# ADR-061: 슬래시(/) 명령어 전용 라우팅 및 비-슬래시 자연어 LLM 100% 전면 위임 (Slash Command Exclusivity & Total LLM Intent Protocol Delegation)

## 1. 개요 (Context)
* **배경**:
  * 사용자의 명시적 지침: *"아직도 룰기반으로 동작하는게 있는 것 같아. / 명령어와같이 명시적으로 요청하는거 말고는 전부 llm은 거치게 변경해."*
  * 기존 `intent_analyzer.py`에는 약 25개 그룹, 800여 라인에 달하는 방대한 정규식 패턴(운동 서사, 구어체 완료, 후미/문두 기록 지시, 파일 조회, 브리핑 트리거, 푸시/동기화 패턴 등)이 산재하여, 사용자의 자연어 발화가 LLM 엔진에 도달하기도 전에 정규식에 의해 가로채져 처리되는 안티패턴이 지속되고 있었다.
  * 이로 인해 사용자의 복합적인 맥락, 미묘한 어조, 대화 히스토리 및 GTD 스킬 지침이 충분히 반영되지 못하고, 정규식 키워드 충돌 및 오탐 가드레일 누더기 코드가 누적되는 문제가 존재했다.

---

## 2. 의사결정 (Decision)

### 2.1 슬래시(/) 명령어 결정론적 전용 라우팅 (`_handle_slash_command`)
1. **슬래시 명령어 한정**:
   * 사용자가 명시적으로 슬래시(`/`)로 시작하는 명령어(`/today`, `/gtd`, `/dday`, `/briefing`, `/schedule`, `/sync`, `/commit`, `/push`, `/log`, `/done`, `/search`, `/weekly`, `/vision`, `/edit`, `/heatmap`, `/location`, `/commute`, `/bus`, `/weather`, `/air`, `/url`, `/status`)를 입력한 경우에만 결정론적 즉각 라우팅을 집행한다.
2. **보류 제안 단순 응답 수용**:
   * 이전 비서 제안에 대한 승인/거절 대기(`pending_log`) 상태에서 단일 응답 토큰("응", "좋아", "아니", "취소")은 사용자 UX의 즉각성을 위해 수용한다.

### 2.2 비-슬래시 모든 자연어 입력의 LLM 100% 전면 위임
1. **정규식 가로채기 완전 철거**:
   * `/`로 시작하지 않는 모든 자연어 입력(일상 대화, 운동 완료, 일기 기록 요청, GTD 할일 등록, 브리핑 질의, 파일 조회 등)은 어떠한 사전 정규식 필터 없이 100% `call_ai_engine_func` (LLM AI 엔진)으로 직접 라우팅된다.
2. **LLM 의도 판별 프로토콜 (Intent Protocol)**:
   * 시스템 프롬프트(`build_system_prompt`)에 `[의도 판별 및 행동 프로토콜 (Intent Protocol - ADR-061)]` 지침을 주입한다.
   * LLM은 대화 맥락, GTD 스킬, 발화 의도를 심층 분석하여 액션이 필요한 경우 첫 줄에 `[INTENT: <tag> <attrs>]` 태그를 출력하고, 다음 줄부터 사용자에게 건넬 정성스러운 응답을 작성한다.
   * `_parse_llm_intent_result`가 태그를 파싱하여 백엔드 실행용 `IntentResult`와 순수 사용자 대화 응답(`ai_response`)으로 분리한다.
3. **시맨틱 스마트 폴백 엔진 (`get_smart_fallback`)**:
   * 단위 테스트 환경(Fast Mode) 및 AGY CLI 미구동/오프라인 환경에서도 LLM과 동일한 `[INTENT: ...]` 태그 프로토콜을 생성하여 초고속 단위 테스트(145개 46초) 및 무중단 안정성을 보장한다.

---

## 3. 결과 및 영향 (Consequences)
* **장점**:
  * `intent_analyzer.py`의 비대한 정규식 가로채기 폭포수가 완전히 철거되고(949줄 ➔ 537줄, 43.4% 경량화), 자연어 발화가 100% 지능형 LLM을 거치도록 일원화됨.
  * 슬래시(/) 명령어는 0.001초 내에 결정론적으로 즉각 처리되면서도, 자연어 대화는 LLM의 풍부한 맥락 추론과 GTD 스킬 지침을 온전히 활용함.
  * 정규식 충돌로 인한 엉뚱한 브리핑/일기 오탐지가 원천 차단됨.
* **검증 결과**:
  * `pytest`: 145개 전체 단위 테스트 100% 통과 (46.91초).
  * `ruff` 및 `mypy`: 42개 전체 파일 무결점 검증 완료.
  * `./scripts/smoke_test.sh`: 전체 라이브 cURL 스모크 테스트 전 항목 통과.
  * `./scripts/service.sh restart`: 백그라운드 무중단 서비스 정상 재시작 및 헬스체크 통과.
