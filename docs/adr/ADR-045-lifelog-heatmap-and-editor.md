# ADR-045: 웹 대시보드 연간 잔디(Heatmap) & 마크다운 인플레이스 에디터 (Contribution Heatmap & In-place Editor)

## 1. 배경 (Context)
Watson은 일상 대화, 텔레그램 사진 전송, GTD 인박스 관리 등을 통해 매일의 라이프로그를 마크다운 파일(`logs/daily/YYYY-MM-DD.md`)로 축적하고 있습니다.
그러나 사용자가 지금까지 얼마나 꾸준히 기록했는지를 한눈에 파악할 수 있는 시각적 통계(기여도 히트맵, 스트릭)가 부재하였고, 과거 작성된 로그의 오탈자나 추가 메모를 웹 상에서 직접 열람·수정하기 위해서는 로컬 에디터나 별도 도구를 사용해야 하는 불편함이 있었습니다.
이에 따라 GitHub 잔디 스타일의 **365일 연간 기여도 히트맵**과 웹 대시보드 내 **인플레이스 분할 마크다운 에디터**를 도입하여, 일상 기록의 동기 부여를 극대화하고 언제 어디서든 손쉽게 일일 로그를 조회·편집·커밋할 수 있는 통합 환경이 요구되었습니다.

## 2. 결정 사항 (Decision)

### 1) HeatmapService 아키텍처 (`app/services/heatmap_service.py`)
* **365일 일일 로그 전수 스캔 및 5단계 기여도 계산**:
  * `logs/daily/*.md` 및 `lifelogs/` 내 모든 마크다운 파일을 정규식으로 파싱하여 날짜별 글자수(`char_count`), 완료 태스크(`completed_tasks`), 미완료 태스크(`pending_tasks`)를 집계.
  * GitHub 잔디 표준에 맞춘 5단계 기여도 레벨(0: 미작성, 1: 가벼운 메모 <200자, 2: 일상 기록 <600자, 3: 충실한 기록 <1200자/태스크, 4: 대형 기록/집중 일과) 정규화.
* **스트릭 및 통계 분석**:
  * 현재 연속 기록 일수(`current_streak`, 오늘 미작성 시 어제부터 역추적), 역대 최장 연속 기록 일수(`longest_streak`), 총 기록 일수, 연간 기록 달성률(%) 집계.
* **마크다운 인플레이스 파일 입출력 및 1기록 1커밋**:
  * `get_lifelog_content(date_str)`: 특정 일자 마크다운 원문 조회 (미작성 시 표준 템플릿 자동 제공).
  * `save_lifelog_content(date_str, content, commit_msg, auto_push)`: 안전한 디스크 저장 후 Git 커밋 및 선택적 원격 푸시를 원자적으로 집행.

### 2) REST API 엔드포인트 (`app/routers/web_router.py`)
* `GET /api/lifelog/heatmap?days=365`: 연간 잔디 그리드 및 스트릭/달성률 요약 통계 JSON 제공.
* `GET /api/lifelog/file?date=YYYY-MM-DD`: 특정 일자 일일 로그 원문 및 메타데이터 반환.
* `POST /api/lifelog/save`: 마크다운 편집 내용 저장 및 Git 커밋·푸시 트리거.

### 3) 웹 대시보드 인터랙티브 UI & 딥링크
* **상단 헤더 잔디 뱃지 (`#heatmap-badge`) & 퀵 액션 칩 (`[✏️ 잔디 & 로그 편집]`)**:
  * 페이지 로드 시 올해 총 기록 일수 및 현재 스트릭을 배지에 즉시 표시하고, 클릭 시 모달 오픈.
* **인터랙티브 모달 (`#lifelog-editor-modal`)**:
  * **연간 잔디 그리드**: 52주 7열 그리드 레이아웃, 기여도 레벨별 색상(0~4), 호버 툴팁(날짜, 글자수, 완료 태스크), 셀 클릭 시 해당 일자 에디터로 즉각 전환.
  * **좌우 분할 에디터**: 좌측 마크다운 소스 편집기 + 우측 실시간 렌더링 뷰어 (Zero-dependency 순수 JS 마크다운 파서 내장).
  * **원터치 커밋 & 푸시**: 커밋 메시지 입력 및 자동 푸시 체크박스 제공.
* **딥링크 연동 (`/?edit=YYYY-MM-DD`)**:
  * URL 파라미터 또는 왓슨/DevBot 안내 링크 클릭 시 해당 일자의 에디터가 즉시 열리는 원스톱 동선 제공.

### 4) 인텐트 분류 및 명령어 20종 확장
* 자연어 ("일기 편집", "잔디 보여줘") 및 슬래시 명령어 (`/edit [날짜]`, `/heatmap`) 지원.
* Watson 및 DevBot에서 편집 딥링크가 포함된 정갈한 안내 카드 제시.
* 텔레그램 네이티브 봇 메뉴 20종에 `/edit`, `/heatmap` 공식 등록.

## 3. 결과 및 영향 (Consequences)
* **긍정적 효과**:
  * 365일 연간 잔디와 연속 스트릭을 통해 매일의 일상 기록에 대한 강력한 시각적 보상 및 습관 형성 지원.
  * 터미널이나 외부 편집기 없이 웹 브라우저에서 실시간 마크다운 프리뷰와 함께 일일 로그를 수정하고 즉시 커밋·푸시할 수 있어 유지보수 편의성이 극대화됨.
* **부정적 효과 및 완화책**:
  * 365일치 파일 스캔 시 디스크 I/O가 발생할 수 있으나, 가벼운 마크다운 텍스트 전용 스캔과 0.05초 미만의 고속 정규식 집계를 통해 성능 저하를 방지함.
