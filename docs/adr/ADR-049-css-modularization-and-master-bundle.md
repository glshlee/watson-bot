# ADR-049: 프론트엔드 스타일시트(CSS) 컴포넌트 모듈화 리팩터링 (CSS Modularization & Master Bundle Architecture)

## 상태 (Status)
**채택됨 (Accepted)** - 2026-09-16 구현 및 cURL 라이브 검증 완료

## 맥락 (Context)
* `app/static/css/style.css`는 시스템의 지속적인 기능 확장(ADR-004 ~ ADR-047)에 따라 3,423라인, 68KB에 달하는 거대 모놀리식 스타일시트로 비대화되었습니다.
* 단일 파일 내에 CSS 변수/리셋, 사이드바/헤더 레이아웃, 대화창 및 메시지 버블, 8종 모달(GTD, 스케줄, 출근길, 텔레그램 메뉴, 잔디 에디터 등), 에이전트 허브 포털, DevBot 콘솔, 모바일 반응형 미디어 쿼리가 한데 뒤섞여 있어 유지보수 시 의도치 않은 CSS 충돌(Cascade Side Effects) 위험이 높았습니다.
* 이에 따라 점진적 리팩터링 계획(Phase 1-2)에 의거하여, 시각적 디자인 변경 없이 CSS를 도메인별 7개 전용 모듈로 분할하고 메인 `style.css`는 `@import url(...)` 오케스트레이터 번들로 경량화하는 아키텍처를 수립했습니다.

## 결정 (Decision)
1. **7개 도메인별 CSS 모듈 분리 (`app/static/css/`)**:
   * `variables.css` (69라인): `:root` CSS 변수(테마, 색상, 라운딩), 글로벌 리셋, 100dvh 높이 고정, 디스플레이 유틸리티, 공통 키프레임 애니메이션.
   * `layout.css` (657라인): 사이드바 드로어, 세션 검색창, 채널 필터 탭, 세션 목록 카드, 연결 상태 배너, 탑 헤더, 유저 프로필, 상태 배지 6종(KST 시계, GTD, 출근, 텔레그램 등).
   * `chat.css` (333라인): 채팅 콘솔 래퍼, 메시지 버블, 아바타, 마크다운(표, 인라인 코드, 블록인용), 입력 바, 왓슨 퀵 액션/칩 바, 실시간 버스 갱신 바.
   * `modals.css` (1,370라인): 모달 기본 오버레이 및 8개 팝업 모달(GTD 경로, 스케줄 타임라인, 출근길 설정, 텔레그램 봇 메뉴 관리, 연간 잔디 에디터 등).
   * `portal.css` (457라인): 에이전트 허브 대시보드 포털(`portal.html`) 전용 레이아웃, 메트릭 카드 4종, 에이전트 카드 그리드.
   * `dev.css` (120라인): DevBot 콘솔(`dev.html`) 전용 브랜치 배지, 툴체인 퀵 바(`/test`, `/lint`, `/commit`), 명령어 칩.
   * `responsive.css` (468라인): 모바일/태블릿(`<=768px`, `<=600px`, `<=400px`) 전용 미디어 쿼리(오프캔버스 드로어, 슬림 입력창, 모달 반응형 레이아웃).
2. **`style.css` 마스터 번들 오케스트레이터 전환**:
   * `style.css`를 3,423라인에서 13라인의 `@import url(...)` 선언문으로 전면 교체하여 기존 HTML 템플릿(`<link rel="stylesheet" href="/static/css/style.css">`)과의 100% 하위 호환성을 완벽 보장.
   * HTTP/2 TCP TLS 터널 환경(ADR-021)을 통해 다중 CSS 병렬 전송 멀티플렉싱을 극대화.

## 결과 및 효과 (Consequences)
* **파일 크기 경량화 및 가독성 혁신**: 메인 `style.css`가 **3,423라인 ➔ 13라인 (99.6% 경량화)**으로 축소되어 스타일 진입점이 극도로 명확해짐.
* **컴포넌트 독립성 및 부작용 방지**: 모달, 채팅, 포털, 반응형 코드가 분리되어 개별 컴포넌트 수정 시 다른 영역에 스타일 오염이 발생하지 않음.
* **100% 하위 호환성 유지**: 기존 모든 HTML 템플릿(`index.html`, `dev.html`, `portal.html`)의 링크를 변경할 필요 없이 모든 7개 하위 모듈이 브라우저에서 자동 로드됨.
* **검증 완료**: 분리된 7개 파일 전수 HTTP 200 응답 검증 완료 및 `./scripts/smoke_test.sh` 40+개 테스트 100% 통과.
