# ADR-025: 브리핑 스케줄 UI 시각화 및 당일 일정 타임라인 (Briefing Schedule Visualization & Daily Timeline)

## 1. Context (배경 및 문제점)
사용자가 웹 콘솔 및 모바일 환경에서 왓슨 비서에게 문의한 핵심 요구사항:
1. **스케줄링 시간대 시각화 부재**:
   - 아침 브리핑과 저녁 일과 회고가 각각 몇 시 기준으로 동작하는지, 언제 어떤 브리핑 모드가 적용되는지 사용자가 웹 UI에서 직관적으로 확인하기 어려웠음.
2. **원클릭 확인 및 당일 일정 연계 요구**:
   - 단순히 텍스트 질문을 던지지 않고도 퀵 바 칩과 팝업 모달을 통해 아침(08:30 KST) / 저녁(20:00 KST) 스케줄 및 당일 일일 로그(`logs/daily/YYYY-MM-DD.md`)에 등록된 시간대별 일정 타임라인을 한눈에 열람하고 즉시 브리핑을 실행할 수 있는 직관적인 UI가 요구됨.

## 2. Decision (결정 사항)

### 2.1 정규 브리핑 시각 및 윈도우 명세 정립
- **🌅 아침 브리핑 (Morning Briefing)**:
  - 정규 스케줄: **매일 오전 08:30 KST**
  - 활성 감지 윈도우: `05:00 ~ 13:59 KST` (자동 브리핑 요청 시 아침 모드 분기)
- **🌇 저녁 일과 회고 (Evening Briefing & Rollover)**:
  - 정규 스케줄: **매일 오후 20:00 (8:00 PM) KST**
  - 활성 감지 윈도우: `14:00 ~ 04:59 KST` (자동 브리핑 요청 시 저녁 모드 분기)

### 2.2 BriefingService 스케줄 브리핑 및 REST API 구현 (`app/services/briefing_service.py`, `app/routers/web_router.py`)
- **`BriefingService.get_schedule_info(date_obj)` & `format_schedule_briefing(date_obj)`**:
  - 현재 KST 시각, 현재 활성 모드, 아침/저녁 정규 시각 및 윈도우 정보 반환.
  - 당일 일일 로그 파일에서 시간대 항목(예: `10:00 데일리 스크럼`)을 정규식으로 파싱하여 구조화된 타임라인 데이터 추출.
- **`GET /api/briefing/schedule` REST 엔드포인트**:
  - 프론트엔드 모달 렌더링 및 외부 연동을 위한 경량 JSON 응답 제공.

### 2.3 LLMProvider 및 SupervisorService 인텐트 라우팅 (`llm_provider.py`, `supervisor_service.py`)
- **`briefing_schedule_inspect` 인텐트 신설**:
  - 슬래시 커맨드(`/schedule`, `/briefing schedule`) 및 자연어 질의("몇 시에 스케줄링 되어있어?", "스케줄 확인", "브리핑 시간 언제야?") 매핑.
  - LLM 호출 지연 없이 결정론적 스케줄 마크다운 표 및 일정 목록 즉시 반환.

### 2.4 모바일 반응형 스케줄 모달 & 퀵 바 시간 뱃지 UI (`index.html`, `dev.html`, `style.css`, `main.js`)
- **원터치 퀵 바 시간 뱃지 노출**:
  - 기존 칩 명칭을 `[🌅 아침 (08:30)]`, `[🌇 저녁 (20:00)]`으로 직관화하여 무클릭으로 시간 인지 가능.
  - `[⏰ 스케줄]` 원터치 칩 신설.
- **인터랙티브 스케줄 팝업 모달 (`#schedule-modal`)**:
  - 현재 KST 시간과 현재 진행 중인 브리핑 모드 뱃지(`[🌅 아침 모드 진행 중]` or `[🌇 저녁 모드 진행 중]`) 하이라이트.
  - 아침/저녁 카드에 정규 시각, 감지 윈도우, 핵심 가치 요약 및 '즉시 실행' 버튼 배치.
  - '오늘의 타임라인 일정' 카드에 당일 일일 로그의 시간대 항목을 시각적 리스트로 바인딩.

## 3. Consequences (영향 및 효과)
- **일과 시간 가시성 극대화**: 아침 08:30, 저녁 20:00 브리핑 주기를 UI 및 대화를 통해 즉각 파악 가능.
- **당일 일정 연동성 강화**: 오늘 로그에 적힌 일정이 스케줄 모달에 자동으로 동기화되어 하루 일정을 한눈에 조망.
- **무지연 결정론적 응답**: 모달 API 호출 및 채팅 질의 모두 0.01초 내외로 초고속 처리되어 쾌적한 UX 제공.
