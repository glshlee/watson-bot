# ADR-054: 슬래시(/) 명령어 팔레트 및 미니멀 입력창 UX 개편 (Slash Command Palette & Minimalist Chat Input UI)

## 상태 (Status)
**채택됨 (Accepted)** - 2026-09-17 구현 및 라이브 cURL/정적 파일 검증 완료

## 맥락 (Context)
* 왓슨 웹 콘솔(`/watson`)의 입력창 상단에는 기능 확장에 따라 총 15개의 칩 버튼(`watson-quick-bar`)이 상시 노출되어 있었습니다.
* 이로 인해 모바일 및 PC 화면에서 입력창 영역이 비대해지고 시각적 노이즈가 심했으며, 원하는 숏컷을 찾기 위해 좌우로 긴 스크롤을 해야 하는 불편함이 발생했습니다.
* 또한, 상단 헤더 배지(출근길, 잔디, 텔레그램 메뉴 등)와의 기능 중복 및 모달 설정 액션과 챗봇 명령어 액션이 혼재되어 있었습니다.
* 사용자 피드백에 따라 과도한 15개 칩 바를 철거하고, Slack, ChatGPT, Discord, Notion 등 모던 채팅 서비스에서 표준으로 자리잡은 **슬래시(`[/]`) 팝오버 커맨드 팔레트(Command Palette)** 방식을 도입하기로 결정했습니다.

## 결정 (Decision)
1. **상시 노출 15개 칩 바 철거 및 `[/]` 액션 버튼 배치**:
   * 입력창 상단의 고정 가로 스크롤 칩 바(`watson-quick-bar`)를 전면 철거.
   * `.input-row` 좌측에 모던한 사각 라운드형 `[/]` 액션 버튼(`#btn-command-palette`)을 배치하여 입력창 공간을 극대화.
2. **플로팅 커맨드 팔레트 컴포넌트 신설 (`app/templates/modals/command_palette.html`)**:
   * 입력창 바로 위에 부드러운 블러(Backdrop blur)와 글래스모피즘 스타일의 플로팅 팝오버 메뉴(`#command-palette`) 탑재.
   * 14개 핵심 기능을 3대 카테고리로 체계적 그룹화:
     * ☀️ **브리핑 & 일정**: 아침 브리핑(`/briefing morning`), 저녁 브리핑(`/briefing evening`), 출근 버스(`/bus`), 스케줄 타임라인 모달, 출근길 맞춤 설정 모달.
     * 📝 **라이프로그 & GTD**: 오늘 일일 로그(`/today`), GTD 현황(`/gtd`), D-Day 마감(`/dday`), 과거 기록 검색(`/search`), 주간 결산(`/weekly`), 연간 잔디&로그 편집기 모달.
     * ⚡ **동기화 & 도구**: 원격 동기화(`/sync`), 원격 Git 푸시(`/push`), 사진 AI 분석(`/vision`), 텔레그램 봇 메뉴 설정 모달.
3. **독립 컨트롤러 모듈 신설 (`app/static/js/modules/command_palette.js`)**:
   * **실시간 타이핑 필터링**: 입력창에 `/` 입력 시 자동으로 팔레트가 열리며, `/` 뒤에 입력하는 키워드(예: `/br`, `/to`, `검색`)에 따라 명령어, 명칭, 설명을 실시간 필터링.
   * **키보드 내비게이션**: `↑` / `↓` 방향키로 아이템 탐색, `Enter` 즉시 실행, `ESC` 닫기 지원.
   * **원클릭 액션 분기**: 모달 액션(`data-action`)은 해당 모달 자동 오픈, 입력형 명령어(`/search `, `/vision `)는 입력창 채우기 및 포커스, 즉시 실행 명령어는 원클릭 즉시 전송.
4. **모바일 반응형 최적화 (`app/static/css/responsive.css`)**:
   * 모바일 화면에서는 가로 전체 너비 확장, 불필요한 서술형 텍스트 숨김을 통해 한 화면에 8개 이상의 명령어가 스크롤 없이 시원하게 보이도록 최적화.
   * 반응형 브레이크포인트를 900px로 확장하여 대화면 모바일(가로모드), 폴더블폰, 소형 태블릿까지 완벽 지원.
5. **모바일 햄버거 메뉴 가시성 및 터치 닫기 안정화**:
   * **햄버거 메뉴 복원**: 모바일 헤더 좌측(`.header-left`)에 `flex-shrink: 0`을 부여하여 우측 배지들에 의한 압축/사라짐을 원천 차단하고, 38x38px 보라색 하이라이트 햄버거 버튼(`☰`)을 영구 노출.
   * **헤더 배지 슬림화**: 우측 6개 배지의 긴 텍스트를 숨기고 34x34px 원터치 정사각형 아이콘 버튼으로 변환하여 헤더 공간 쾌적화.
   * **원터치 닫기 버튼 & 백드롭**: 팔레트 헤더에 전용 `[✕ 닫기]` 터치 버튼과 반투명 백드롭을 추가하고, `touchstart` 리스너를 연동하여 모바일에서 지연 없이 즉시 닫히도록 보장.

## 결과 및 효과 (Consequences)
* **극적인 시각적 정돈 (미니멀리즘 UX)**: 지저분했던 15개 버튼이 완전히 정리되어 순수한 대화 중심의 깔끔하고 쾌적한 인터페이스 확립.
* **100% 하위 호환성 유지**: 기존 모달 컨트롤러들이 참조하던 ID(`btn-schedule-view`, `btn-commute-view`, `btn-open-editor`, `btn-telegram-menu-view`)를 팔레트 아이템에 그대로 보존하여 기존 모달 로직 수정 없이 100% 정상 작동.
* **접근성 혁신**: 마우스 클릭뿐 아니라 키보드(`/` 입력 후 `Enter`)만으로 모든 왓슨 기능을 빛의 속도로 실행 가능.
