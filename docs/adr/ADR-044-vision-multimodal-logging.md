# ADR-044: 사진·영수증·운동인증 Vision AI 멀티모달 분석 & 스마트 기록 (Vision Multimodal Lifelogging)

## 1. 배경 (Context)
기존 Watson 시스템은 텔레그램을 통해 사진 수신 시 이미지 파일을 디스크에 저장한 뒤, 사용자가 입력한 단문 캡션 또는 기본 텍스트("일상 사진 메모")를 바탕으로 `Media & Attachments` 섹션에 단순 이미지 링크(`![photo](...)`)로만 일괄 기록하였습니다.
그러나 모바일 환경에서 사용자의 가장 자연스럽고 빈번한 일상 캡처 방식은 **사진 촬영**(식사/맛집, 애플워치 운동 결과 화면, 영수증, 회의 화이트보드/포스트잇 메모)입니다.
사진 속에 담긴 시각 정보(종목, 심박수, 칼로리, 상호명, 지출 금액, 필기 내용 등)를 멀티모달 시각 지능(Vision AI)으로 자동 추출하고, 도메인별 라이프로그 마크다운 서식 및 GTD 태스크로 정제하여 2단계 사전 검토(ADR-029)로 제시하는 통합 파이프라인의 구축이 요구되었습니다.

## 2. 결정 사항 (Decision)

### 1) VisionService 멀티모달 시각 지능 아키텍처 (`app/services/vision_service.py`)
* **5대 도메인 자동 분류 및 메트릭 추출**:
  1. 🏃 **운동 인증 (`workout`)**: 러닝 앱, 애플워치, 인바디 화면 ➔ 종목, 운동 시간, 거리(km), 칼로리(kcal), 심박수 추출 및 `## 🏃 운동 & 건강 (Workout & Health)` 섹션에 정갈한 표/불릿 포맷팅.
  2. 🍲 **식사 & 맛집 (`meal`)**: 음식 및 식당 사진 ➔ 메뉴명, 시간대 분석 및 `## 💡 순간 메모 / 캡처` 또는 `## 📝 생각 및 일기` 미식 저널 포맷팅.
  3. 🧾 **영수증 & 지출 (`receipt`)**: 상호명, 결제 일시, 금액 추출 및 카드번호(`****-****-****-****`) 자동 마스킹, GTD 가계부 정리 태스크(`- [ ] 가계부 정리 및 지출 확인: [상호] [금액] (~YYYY-MM-DD)`) 동시 생성.
  4. 📝 **메모 & 손글씨 (`memo`)**: 회의 화이트보드, 포스트잇 손글씨 텍스트화 및 GTD 검토 액션 태스크 생성.
  5. 🖼️ **일상 사진 (`general`)**: 일상 풍경, 반려견, 가족 모먼트 요약 포맷팅.
* **듀얼 엔진 & 무중단 폴백**:
  * 1순위: Google Gemini 1.5 Flash Vision REST API (Base64 인라인 데이터 및 JSON Schema 응답).
  * 2순위: 휴리스틱 캡션 분석 및 메타데이터 기반 스마트 폴백 엔진으로 API 키 부재 또는 오프라인 상태에서도 100% 무중단 안정성 보장.

### 2) 2단계 사전 검토 워크플로우 연계 (ADR-029)
* 사진 수신 시 즉시 커밋하지 않고, 추출된 지표와 저장 경로, 마크다운 초안이 담긴 **초안 카드(Draft Preview Card)**를 텔레그램 인라인 키보드(`[✅ 응, 기록해줘]`, `[❌ 아니야]`)와 함께 사전 제시.
* 승인 발화("응", "좋아", "이대로 기록해줘") 또는 인라인 버튼 클릭 시 1회 원자적 Git 커밋/푸시 집행.
* 단, 캡션에 `/log` 또는 `!`가 포함되거나 사용자가 즉시 기록을 지시한 경우 사전 검토를 건너뛰고 즉시 커밋·푸시하는 **패스트트랙** 동시 지원.

### 3) 텔레그램 네이티브 봇 메뉴 18종 확장 & REST API
* `TelegramService.DEFAULT_COMMANDS`에 `/vision` ("사진·영수증·운동인증 Vision AI 분석 안내") 추가 등록.
* `POST /api/vision/analyze`: 사진 멀티파트 업로드 및 시각 분석 JSON/초안 반환.
* `POST /api/vision/upload-and-log`: 사진 업로드 및 2단계 검토/패스트트랙 즉시 기록 엔드포인트.
* DevBot 콘솔에 `/vision [경로] [캡션]` 전용 엔지니어링 도구 체인 및 웹 콘솔 퀵 액션 칩(`[📷 사진 분석]`) 추가.

## 3. 결과 및 영향 (Consequences)
* **긍정적 효과**:
  * 사진 한 장 전송만으로 운동 수치, 영수증 금액, 식사 메뉴가 정갈한 마크다운 일기와 GTD 태스크로 자동 변환되어 일상 기록 허들이 획기적으로 낮아짐.
  * 영수증의 민감 정보(카드번호)가 자동으로 마스킹되어 개인정보 보안이 강화됨.
  * 2단계 사전 검토 워크플로우를 통해 오인식에 따른 잘못된 파일 수정을 사전에 방지함.
* **부정적 효과 및 완화책**:
  * 멀티모달 Vision API 호출 시 네트워크 지연이 발생할 수 있으나, 15초 타임아웃 및 룰 기반 지능형 폴백을 적용하여 응답 지연을 방지함.
