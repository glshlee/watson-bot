# ADR-006: 모바일 접근성을 위한 텔레그램 봇 연동 및 인라인 키보드 인터랙션 아키텍처

* **상태 (Status)**: 승인됨 (Accepted)
* **날짜 (Date)**: 2026-09-05
* **작성자 (Author)**: Watson Core Team & User

---

## 1. 맥락 (Context)
Watson 애플리케이션이 24시간 원격 서버에 상시 가동될 때, 사용자가 PC 브라우저를 켜지 않고도 이동 중이거나 일상생활 속에서 언제 어디서나 스마트폰을 통해 라이프로그를 남기고 AI 비서와 소통할 수 있는 모바일 채널이 필수적이다.
이를 위해 글로벌 메신저인 텔레그램(Telegram) 봇을 시스템 코어와 연동한다.

---

## 2. 의사결정 (Decision)

### 2.1. 비동기 롱 폴링(Long Polling) 기반 통합 서비스
* 도메인 및 SSL 인증서 구비가 불필요하고 방화벽 포트 개방 없이 어디서나 즉시 작동하는 **Telegram Long Polling (`getUpdates`)** 방식을 채택한다.
* FastAPI의 수명 주기(`lifespan`) 이벤트와 연동하여 백그라운드 비동기 태스크로 구동하며, 토큰 미설정 시에는 안전하게 비활성화 상태를 유지한다.

### 2.2. 세션 분리 및 스마트 비서 파이프라인 연동 (ADR-002, ADR-004 준수)
* 세션 ID: `telegram:{chat_id}` 형태로 웹 세션과 안전하게 격리 보존한다.
* 비서 의도 분리:
  * 단순 잡담: 텔레그램 텍스트 답변만 회신 (커밋 X).
  * 라이프로그 제안 (`log_suggest`): 비서 응답과 함께 **인라인 키보드 버튼(`[✅ 응, 기록해줘]`, `[❌ 아니야]`)**을 메시지에 동적 부착.
  * 승인/직접기록: 오늘 자 마크다운에 즉시 반영하고 GitHub 자동 커밋 & 푸시 집행.

### 2.3. 화이트리스트 보안 및 미디어 처리
* `TELEGRAM_ALLOWED_CHAT_IDS` 환경 변수를 통해 인가된 사용자만 봇과 상호작용하도록 보안을 적용한다.
* 사진 수신 시 로컬 저장소에 안전하게 다운로드 후 마크다운 `Media & Attachments` 섹션에 삽입한다.

---

## 3. 결과 및 영향 (Consequences)

### Positive (긍정적 영향)
* **최고의 모바일 접근성**: 스마트폰 메신저 앱으로 언제 어디서나 삶의 기록과 대화 가능.
* **배포 유연성**: 포트포워딩이나 도메인 없이 토큰만 넣으면 오라클 클라우드/홈서버 어디서나 100% 즉시 작동.
* **일관된 UX**: 웹 대시보드와 동일한 지능형 비서 로직과 1기록 1커밋 정책 공유.
