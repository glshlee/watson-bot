# ADR-035: Open-Meteo 무설정 오픈 API 기반 실시간 날씨 및 대기질 연동 (Live Weather & Air Quality Open-Meteo Integration)

## 1. Status (상태)
**Accepted (채택됨)** - 2026-09-14

---

## 2. Context (배경 및 문제 정의)
* **공공데이터포털 API의 복잡성 및 시뮬레이션(Mock) 한계**:
  * 기존 브리핑 및 날씨 조회는 공공데이터포털(기상청 단기예보, 에어코리아 대기질) 연동 설계를 기반으로 하였으나, 인증키 발급/승인 대기, 쿼터 제한, 까다로운 격자 좌표 변환으로 인해 기본 상태가 시뮬레이션(Mock) 모드로 동작함.
  * 사용자가 "공공데이터포털은 지금 mock인거지?"라고 질의하며, 번거로운 키 등록 없이 즉시 실제 기상과 대기질을 받아볼 수 있는 **무설정(Zero-Key) 오픈 API 방식(Option 2)**을 공식 채택하기로 결정함.
* **실시간 정확성 및 지연 시간 요구사항**:
  * 아침 브리핑 및 실시간 질의 시 0.1~0.3초 이내로 신속하게 실시간 데이터가 응답되어야 하며, 네트워크 불안정 시에도 무중단 서비스가 보장되어야 함.

---

## 3. Decision (결정 사항)

### 3.1 Open-Meteo 실시간 기상/대기질 엔진 구축 (`app/services/weather_service.py`)
1. **Zero-Key 글로벌 오픈 API 활용**:
   * API 키 발급이 불필요한 Open-Meteo Forecast API 및 Air Quality API를 연동하여 위도/경도 기반 실시간 기온, 체감온도, WMO 기상 코드, 일일 강수확률, PM10, PM2.5를 직접 조회.
2. **한국 환경부 기준 대기질 등급 정규화**:
   * PM10 (좋음 <=30, 보통 <=80, 나쁨 <=150, 매우나쁨 >150)
   * PM2.5 (좋음 <=15, 보통 <=35, 나쁨 <=75, 매우나쁨 >75)
3. **지능형 우산 팁(Umbrella Tip) 생성**:
   * 강수확률 및 WMO 기상 코드(비/소나기/눈/뇌우 등)를 결합하여 `우산 필수 ☔`, `접이식 우산 추천 🌂`, `우산 불필요 ☀️`를 결정론적으로 제안.
4. **인메모리 캐싱 및 고탄력 폴백(Fallback)**:
   * 10분(600초) TTL 인메모리 캐시를 적용하여 불필요한 중복 네트워크 호출 차단.
   * 타임아웃(3.5초) 및 네트워크 오류 시 최근 캐시 또는 스마트 시뮬레이션 데이터로 무중단 안전 폴백.

### 3.2 위경도(Latitude/Longitude) 지오코딩 및 설정 확장 (`GeoService`, `CommuteConfigService`)
1. **스마트 지오코딩 위경도 좌표 보강 (`app/services/geo_service.py`)**:
   * 서울 25개 구 및 전국 주요 지역(판교, 분당, 광교, 동탄, 평촌, 부산 해운대 등)의 위도(`lat`)와 경도(`lon`)를 내장하여 지오코딩 시 위경도를 자동 산출.
2. **설정 영속화 및 투명성 배지 (`app/services/commute_config_service.py`)**:
   * `config/commute_config.json`에 `latitude`, `longitude`를 자동 영속화.
   * 브리핑 및 날씨 카드에 `(📡 Open-Meteo 실시간 라이브 API - HH:MM 기준)` 출처 배지를 명시하여 데이터 신뢰도 제공.

## 4. Consequences (파급 효과)

### 긍정적 효과
* **완전한 무설정(Zero-Configuration) 실시간 데이터**:
  * 사용자가 API 키를 전혀 발급받지 않아도 즉시 실제 서울 성동구 금호동(또는 설정된 모든 동네)의 실시간 날씨와 미세먼지를 수신.
* **초고속 응답 속도**:
  * 평균 150ms 내외의 초고속 응답과 10분 캐시로 브리핑 지연 제로 달성.
* **신뢰성 있는 기상 의사결정**:
  * 실시간 강수확률과 환경부 기준 미세먼지 수치에 기반한 정확한 우산 팁과 마스크 착용 가이드 제공.
