# ADR-012: 테스트 샌드박스 격리(Smoke Test Isolation) 및 대화형 지시어 문맥 역추적

* **상태 (Status)**: 승인됨 (Accepted)
* **날짜 (Date)**: 2026-09-08
* **작성자 (Author)**: Watson Core Team & User

---

## 1. 맥락 (Context)
사용자가 텔레그램을 통해 첫 버디 '고든'의 퇴사 사연과 아쉬운 감정을 나눈 뒤 **"응 오늘 로그에 기록해줘"**라고 지시하였으나, Watson이 고든 사연을 기록하지 않고 **`- [05:14] 응 오늘 로그에`**라는 지시어 문구를 그대로 마크다운에 기록하는 심각한 파싱 오류가 발생했다. 또한, 사용자가 언급한 적 없는 **`오늘 저녁 한강 러닝 5km 뛰었어`**, **`프로젝트 기획 완료`** 등의 더미 데이터가 실제 개인 GitHub 저장소(`life_log`)에 커밋 및 푸시되는 데이터 오염이 확인되었다.

### 원인 분석
1. **스모크 테스트의 실서버 GTD 저장소 오염 (Test Leakage)**:
   * `./scripts/smoke_test.sh`는 실서버 포트 8000에 대해 cURL API 테스트를 수행하면서, 당시 실서버가 연결하고 있던 사용자의 실제 GTD 저장소(`/home/ubuntu/workspace/life_log`)에 테스트 메시지("한강 러닝 5km", "프로젝트 기획 완료")를 직접 요청하여 마크다운 파일을 오염시켰다.
   * 이후 사용자가 라이프로그를 기록할 때 저장소의 전체 변경사항이 함께 커밋/푸시되어 원격 GitHub에 노출되었다.
2. **지시어 접두어를 본문 내용으로 오인한 단일 문장 정규식 결함**:
   * 사용자가 고든 사연을 공유한 뒤 "응 오늘 로그에 기록해줘"라고 입력했을 때, `pending_log`가 없어 일반 명령으로 분류되었다.
   * 이때 직접 기록 정규식이 `(.*?)기록해줘` 패턴으로 인해 `"응 오늘 로그에"`를 유효한 기록 내용(`main_part`)으로 추출하여, 사연 원문 대신 지시어 텍스트 자체를 마크다운에 영속화했다.

---

## 2. 의사결정 (Decision)

### 2.1. 스모크 테스트 샌드박스 완벽 격리 (Test Sandbox Isolation)
* `scripts/smoke_test.sh` 실행 시:
  1. 실서버의 기존 GTD 경로(`ORIGINAL_GTD_PATH`)를 메모리에 백업.
  2. 임시 Git 저장소(`/tmp/watson_smoke_gtd_XXXXXX`)를 생성하고 실서버 GTD 작업 경로를 임시 변경.
  3. 모든 API 테스트(제안, 승인, 직접 기록 등)를 임시 샌드박스에서만 수행.
  4. 테스트 종료(또는 비정상 종료 시 trap) 시 원래의 사용자 GTD 경로로 100% 복원 및 임시 디렉토리 제거.
* **사용자의 실제 개인 GTD 저장소는 어떠한 테스트 환경에서도 절대 건드리지 않음**을 보장.

### 2.2. 대화형 지시어 문맥 역추적 (Conversational Directive Resolution)
* 사용자의 발화에서 감탄사/승인어("응", "네", "어", "그래", "좋아")와 목적지("오늘", "로그에", "일기에"), 행동("기록해줘", "남겨줘")을 제거한 잔여 텍스트의 길이가 2자 이하인 경우, 이를 새로운 본문이 아닌 **"직전 대화 내용을 오늘 로그에 기록하라"는 지시어**(`is_pure_directive`)로 판별.
* 세션 히스토리(`history`)에서 명령어가 아닌 가장 최근의 유의미한 사용자 사연(고든 퇴사 이야기 등)을 역추적 추출하여 대상 마크다운 파일에 기록.
* 직접 기록 정규식(`explicit_match`) 내부에서도 지시어 접두어를 걸러내어, 지시어 텍스트가 본문으로 오인되는 것을 원천 차단.

---

## 3. 결과 및 영향 (Consequences)

### Positive (긍정적 영향)
* **실서버 사용자 데이터 무결성 보장**: 테스트 스크립트 실행으로 인한 더미 데이터 생성이 100% 차단됨.
* **자연스러운 구어체 지시 완벽 대응**: "응 오늘 로그에 기록해줘", "오늘 일기에 적어줘", "응 기록해줘" 등의 자연스러운 승인/지시 시 이전 대화의 긴 사연을 정확하게 복원하여 마크다운에 영구 보존.
