# ADR-036: 키워드 정규식 가로채기 철거 및 LLM 자연어 위임·부정 피드백 가드레일

## 1. 배경 (Context)
* 기존 왓슨 시스템은 일과/생각/업무 감지를 위해 `workout_keywords`, `idea_keywords`, `work_keywords`, `life_keywords` 등의 방대한 키워드 리스트를 활용한 단순 서브스트링(Substring) 정규식 매칭을 수행해왔음.
* 2026-09-14 텔레그램 대화 중 사용자가 아침 브리핑의 구매 목록(두루마리 휴지, 커피원두, 고양이 모래)에 대해 **"휴지는 선물받아서 구매할 필요가 없어."**라고 발화하였으나, **"필[요가] 없어"**의 **"요가"**가 `workout_keywords`에 부분 일치하면서 왓슨이 뜬금없이 **"건강을 챙기시는 모습이 정말 멋지십니다! 🏋️ 오늘 운동 기록(Workout & Health)에 기록해 둘까요?"**라고 오작동하는 심각한 오탐지(False Positive) 결함이 발생함.
* 또한 사용자의 발화가 불필요/취소/제외/피드백 표현임에도 불구하고 키워드 하나에 걸려 무조건 `log_suggest`를 띄우고 세션 `pending_log`를 오염시키는 문제가 드러남.
* 고성능 LLM(Gemini / AGY)을 탑재하고 있으면서도 앞단의 조잡한 키워드 정규식이 LLM 호출을 무차별 가로채는 역설(Interception Anti-Pattern)을 해결해야 함.

## 2. 결정 사항 (Decision)
1. **키워드 정규식 가로채기(Regex Interception) 전면 철거**:
   * 단순 명사 단어 포함 여부만으로 무조건 초안 템플릿을 생성하던 `idea_keywords`, `work_keywords` 블록을 완전히 삭제함.
   * 사용자가 명시적으로 기록을 명령하지 않은 일상 생각, 고민, 업무, 잡담 등은 100% LLM(`_call_ai_engine`)으로 전달하여 문맥에 맞는 자연스러운 비서 대화를 나누도록 일원화함.
2. **부정 / 불필요 / 취소 / 피드백 가드레일 최우선 적용 (`negative_feedback_patterns`)**:
   * `"필요 없어"`, `"필요가 없어"`, `"안 사도 돼"`, `"안 해도 돼"`, `"선물받아"`, `"취소"`, `"삭제"`, `"어때?"` 등 불필요/취소/피드백/의문 표현이 감지되면 어떠한 경우에도 `log_suggest` 초안으로 빠지지 않고 즉시 LLM 대화로 위임함.
3. **서사적 운동/일상 완료 진술문(Narrative Action)에 한정한 안전한 초안 제안**:
   * 운동(`Workout & Health`)은 단순 명사("요가", "pt")가 아닌 실제 운동 행위를 수행/완료했다는 서사 진술(`스쿼트 100kg 성공`, `러닝 5km 뛰고 왔어`, `요가 수업 다녀왔어`, `푸시업 100개 완료` 등 과거형/완료형 서술어 결합)에 한해서만 초안 제안.
   * "요가"의 경우 `(?<![필중가])요가` 및 서술어 결합 패턴으로 서브스트링 오탐지를 원천 차단.
4. **오염된 텔레그램 세션 보류 상태 및 GTD 구매 목록 정제**:
   * DB에 걸려 있던 오탐지 `pending_log`를 초기화하고, GTD `inbox.md`의 구매 목록에서 사용자의 의도대로 두루마리 휴지를 선물 수령으로 완료 처리함.

## 3. 결과 및 영향 (Consequences)
* **긍정적 영향**:
  * "구매할 필요가 없어", "살 필요 없는데", "미팅 취소됐어" 등의 구어체 발화에서 엉뚱한 운동/업무 일기 초안이 뜨는 현상이 100% 차단됨.
  * LLM이 대화 맥락을 온전히 살려 자연스럽고 센스 있는 피드백 및 조언을 제공함.
  * 복잡하게 얽혀 있던 정규식 누더기 코드가 대폭 슬림화되고 유지보수성이 크게 향상됨.
* **검증 결과**:
  * 단위 테스트 13건 100% PASSED (신규 회귀 방지 테스트 포함)
  * cURL 라이브 스모크 테스트(`./scripts/smoke_test.sh`) 전 항목 100% 통과
  * Ruff 린트 및 Mypy 타입 무결성 검증 완료
