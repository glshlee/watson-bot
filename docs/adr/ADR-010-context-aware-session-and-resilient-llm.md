# ADR-010: 세션 대화 맥락 참조 기록(Context-Aware Logging) 및 AGY 엔진 경량화/회복 탄력성

* **상태 (Status)**: 승인됨 (Accepted)
* **날짜 (Date)**: 2026-09-08
* **작성자 (Author)**: Watson Core Team & User

---

## 1. 맥락 (Context)
사용자가 텔레그램을 통해 개인적이고 깊은 감정/일과(태아 초음파 결과 및 아내 케어, 집들이 등)를 나눈 뒤, **"오늘 로그에 내가 아까 말한 내용도 기록해줘. 내 감정이니까"** 또는 긴 이야기 뒤에 **"이 내용 오늘 로그에 기록해줘"**라고 요청했음에도, Watson이 이전 대화를 기억하지 못하고 `"네, 사용자님 말씀 잘 듣고 있습니다! 😊 오늘 하루 있었던 일과나..."`라는 초기 기계식 폴백 인사말을 반환하는 심각한 맥락 단절(Amnesia) 문제가 발생했다.

### 원인 분석
1. **이전 대화 맥락 참조 기록(`history` 기반 참조 해결) 부재**:
   * 기존 로직은 `pending_log`가 사전에 세팅되어 있는 경우의 승인("응 좋아")만 처리했으며, 사용자가 "아까 말한 내용", "방금 이야기", "이전 내용"을 기록해달라고 요청할 때 대화 기록(`history`)에서 이전 사용자 발화를 역추적하여 추출하는 참조 해결 파이프라인이 없었다.
2. **엄격한 단일 행 정규식 제약**:
   * 직접 기록 명령 감지 정규식이 `^...$` 단일 행 기준으로 작성되어, 줄바꿈(`\n\n이 내용 오늘 로그에 기록해줘`)이나 문장 뒤에 부연 설명(`. 내 감정이니까`)이 붙은 복합 문장을 감지하지 못하고 일반 대화(`chat_only`)로 누락시켰다.
3. **AGY CLI 프롬프트 비대화 및 30초 타임아웃 초과**:
   * 이전 어시스턴트 답변(GTD 브리핑 등 1,500~2,000자)이 포함된 `history`를 축약 없이 그대로 `agy -p`에 전달하여 프롬프트가 과도하게 비대해졌다.
   * 싱글/듀얼 코어 클라우드 VM 환경에서 긴 프롬프트 추론에 35초 이상 소요되어 30초 타임아웃에 걸렸고, 에러 캐치 후 기계적인 더미 인사말로 폴백되었다.

---

## 2. 의사결정 (Decision)

### 2.1. 세션 맥락 참조 기록 파이프라인 구현 (Context Reference Resolution)
* 사용자가 "아까 말한 내용", "방금 말한 거", "이전 내용", "앞서 말한 이야기" 등을 기록해달라고 할 때:
  1. `history`를 역순으로 탐색하여 가장 최근의 유의미한 사용자 발화 원문을 추출.
  2. 추출된 원문을 `log_explicit` 기록 대상으로 자동 바인딩.
  3. 카테고리를 추론("감정/생각" ➔ `Ideas & Thoughts` 또는 `Daily Notes & Diary`)하여 즉시 마크다운에 영속화하고 Git 커밋/푸시 집행.
* 멀티라인 입력(`[긴 본문]\n\n이 내용 오늘 로그에 기록해줘`)에서도 본문과 기록 지시어를 지능적으로 분리하여 즉시 기록 처리.

### 2.2. AGY 프롬프트 경량화 및 타임아웃/회복 탄력성 강화
* **히스토리 경량 요약**: `_call_ai_engine`에 전달되는 이전 어시스턴트의 긴 브리핑/답변을 최대 250자로 안전하게 슬라이싱하여 프롬프트 토큰 수를 70% 이상 절감.
* **타임아웃 확장**: CPU 부하 상황을 고려하여 `timeout`을 30초에서 50초로 확장.
* **지능형 맥락 보존 폴백**: 만에 하나 서브프로세스 지연 시에도 기계적 초기 인사가 아닌, 대화 맥락과 사용자 요청에 공감하는 반응을 반환하도록 개선.

---

## 3. 결과 및 영향 (Consequences)

### Positive (긍정적 영향)
* **완벽한 대화 세션 연속성**: "아까 말한 거 기록해줘" 한마디로 직전 대화의 긴 사연과 감정을 완벽히 복원하여 마크다운에 영구 보존.
* **AGY 응답 속도 대폭 개선**: 프롬프트 다이어트를 통해 평균 응답 시간이 10~15초 이내로 단축되어 타임아웃 위험 제거.
* **유연한 명령 인식**: 줄바꿈이나 부연 설명이 포함된 자연스러운 명령어도 100% 라이프로그 기록으로 연결.
