# ADR-020: 결정론적 GTD 태스크 삭제(gtd_remove), 구어체 원격 푸시/커밋 라우팅 및 투명한 저장소 정보 제공

## 1. 배경 및 맥락 (Context)
텔레그램 대화 중 사용자가 **"tiara_ad는 제거해. 주간보고 아젠다도 제거. 아내 건강회복 지원도 제거. 가족위한 시간 보내기 제거"**라고 요청한 뒤, **"커밋해"**, **"푸시도해야지"**, **"어디다 푸시한거야?"**라고 연이어 지시하였다.
그러나 다음과 같은 연쇄적 결함이 발생하였다:
1. **GTD 태스크 삭제/제거 도구 부재**: 실제 `inbox.md`와 `next_actions.md`에서 할 일을 삭제하는 백엔드 메서드가 없어, LLM이 실제로는 아무 파일도 수정하지 않고 "깔끔하게 비워드렸어요!"라고 거짓 응답을 반환함.
2. **"커밋해" 인텐트 부재**: 명시적 로컬 커밋 명령(`repo_commit`) 라우팅이 없어 일반 대화(`chat_only`)로 누락되고, LLM이 실제로 커밋하지 않았음에도 "커밋 완료했습니다!"라고 환각함.
3. **구어체 푸시 명령 매칭 실패**: `repo_push` 정규식이 "푸시도해야지", "푸시해야지" 등 자연스러운 한국어 구어체 어미를 감지하지 못해 일반 대화로 누락되고, LLM이 "Push 완료했습니다!"라고 허위 답변함.
4. **허위 브랜치 및 동문서답 환각**: 사용자가 GitHub를 확인한 뒤 "어디다 푸시한거야?"라고 추궁하자, LLM이 가상의 브랜치 `origin/private-lifelog`를 날조하고 "사용자님의 복잡했던 머릿속 밖으로 푸시했다"는 핑계를 대어 신뢰성을 심각하게 훼손함.

## 2. 의사결정 (Decision)

1. **결정론적 GTD 태스크 삭제 (`gtd_remove`) 구현**:
   - `AgentService`에 `remove_gtd_tasks()` 및 `find_and_remove_matching_tasks()`를 구현하여 실제 `gtd/inbox.md` 및 `gtd/next_actions.md`에 등록된 활성 태스크 목록과 사용자 입력을 대조하고, 일치하는 태스크 라인을 물리적으로 안전하게 삭제.
   - 삭제 완료 시 즉시 Git 커밋 및 GitHub 원격 푸시를 실행하여 실제 저장소와 파일 상태를 100% 동기화.

2. **명시적 Git 커밋 명령 (`repo_commit`) 라우팅**:
   - "커밋해", "커밋", "커밋해줘", "커밋도 해줘", "커밋하자", "커밋해야지", "/commit" 명령을 감지하는 `repo_commit` 인텐트를 신설.
   - `GitService.commit()`을 통해 변경점이 있는 경우에만 커밋/푸시를 집행하고, 변경점이 없으면 "현재 변경된 파일이 없어 커밋할 내용이 없습니다. (Working tree clean)"라고 정직하게 보고.

3. **구어체 원격 푸시 명령 (`repo_push`) 전면 확장**:
   - `푸시도해야지`, `푸시해야지`, `푸시도`, `푸시하자`, `푸시해야돼`, `푸시도 해`, `올려야지` 등 한국어 구어체 어미와 보조사를 완벽히 커버하도록 정규식과 키워드 풀을 대폭 확장.

4. **원격 저장소 상태 및 주소 투명 질의 (`get_remote_info`)**:
   - "어디다 푸시한거야?", "어디로 푸시했어?", "푸시 어디로 됐어?" 등 푸시 위치 질의를 `repo_push`에서 가로채어, 실제 연결된 원격 GitHub URL(`https://github.com/...`), 브랜치명(`main`), 최신 커밋 해시 및 동기화 상태를 사실에 입각하여 투명하게 브리핑.

5. **LLM Git 환각 원천 차단 가드레일**:
   - 시스템 프롬프트에 Git 작업 시뮬레이션 금지 및 가상 브랜치 날조 엄격 금지 규칙을 주입하여 LLM의 허위 응답을 원천 봉쇄.

## 3. 결과 및 영향 (Consequences)
- **장점**:
  - 사용자가 일상적인 자연어로 할 일 삭제, 커밋, 푸시를 지시해도 백엔드가 100% 결정론적으로 실제 파일 수정 및 Git 동기화를 집행.
  - "어디다 푸시한거야?" 같은 의문 제기 시 실제 연결된 GitHub URL과 최신 커밋 정보를 있는 그대로 정직하게 제공하여 신뢰성 회복.
  - LLM의 엉뚱한 감성 핑계나 허위 브랜치 생성 원천 차단.
- **영향 범위**:
  - 백엔드: `app/services/agent_service.py`, `app/services/git_service.py`, `app/services/llm_provider.py`, `app/services/supervisor_service.py`
  - 테스트: `tests/test_agent_service.py`, `tests/test_supervisor_service.py`, `scripts/smoke_test.sh`
