# ADR-016: 모바일 퍼스트 반응형 웹 인터페이스 및 터치 UX 최적화

## 1. 배경 (Context)
ADR-015를 통해 Cloudflare Tunnel과 HTTP Basic 인증을 연동하여 모바일 및 외부 브라우저에서 Watson 웹 대시보드에 접근할 수 있게 되었다.
그러나 스마트폰 화면(360px~430px)으로 접속했을 때 다음과 같은 사용성 저하가 발생하였다:
1. **고정 280px 사이드바 화면 잠식**: 사이드바가 데스크톱처럼 좌측에 고정 노출되어 모바일 화면의 70~80%를 차지하고 채팅 영역이 좁아져 정상적인 대화 및 조작이 불가능함.
2. **상단 헤더 및 배지 겹침**: 상단 바의 제목, GTD 연동 배지, 깃허브 아이콘 등이 한 줄에 뭉개져 줄바꿈이 깨지거나 버튼 터치가 어려움.
3. **입력창 및 가상 키보드 불편**: iOS Safari 등 모바일 브라우저에서 폰트 크기가 작을 때 발생하는 자동 확대(Auto-zoom) 현상과 뷰포트 높이(`100vh`) 이슈로 키보드가 올라올 때 스크롤이 어긋남.
4. **터치 타깃 및 빠른 액션 간격**: 비서 제안 버튼("응, 기록해줘", "아니야")의 마진(`48px`)이 모바일 화면 밖으로 벗어남.

## 2. 결정 사항 (Decision)
1. **모바일 오프캔버스 드로어(Off-Canvas Drawer) & 백드롭 적용**:
   - 화면 폭 768px 이하 모바일 환경에서 사이드바를 기본 숨김(`translateX(-100%)`) 처리하고, 상단 햄버거 메뉴 버튼으로 부드럽게 슬라이드되는 오프캔버스 드로어로 전환.
   - 반투명 블러 백드롭(`sidebar-backdrop`)을 제공하여 외부 터치 시 또는 세션 선택 시 드로어가 자동으로 닫히도록 구현.
2. **동적 뷰포트(100dvh) 및 iOS Safe Area 지원**:
   - 모바일 브라우저 주소창/하단바 변화에 반응하는 `100dvh` 높이 체계 적용.
   - 뷰포트 메타태그에 `viewport-fit=cover`를 적용하고, 하단 입력창에 `env(safe-area-inset-bottom)`을 반영하여 노치/홈 인디케이터 간섭 차단.
   - 모바일 입력창(`textarea`, `input`) 기본 폰트 크기를 `16px`로 설정하여 iOS 사파리의 원치 않는 자동 줌 인(Auto-zoom)을 원천 방지.
3. **헤더 및 카테고리 바 반응형 최적화**:
   - 모바일에서는 간결한 타이틀("Watson 콘솔")과 축약된 배지(경로 말줄임)를 적용하고 보조 텍스트를 숨겨 화면 공간 확보.
   - 빠른 액션 버튼(`.btn-quick`) 여백을 모바일에 맞추어 재정렬하고 터치 편의성(최소 높이 38px~44px) 확보.
4. **테스트 환경 격리 (`tests/conftest.py`)**:
   - 단위 테스트 실행 시 `.env`의 `WEB_AUTH_ENABLED` 설정과 무관하게 인증을 비활성화하는 기본 fixture를 제공하여 CI/로컬 테스트 안정성 확보.

## 3. 결과 및 영향 (Consequences)
- **장점**:
  - 모바일 스마트폰, 태블릿, 데스크톱 모든 디바이스에서 최적의 채팅 UX 제공.
  - 모바일 브라우저에서 네이티브 메신저 앱과 유사한 직관적인 드로어 탐색 및 터치 경험 제공.
- **검증**:
  - `pytest` (모든 스위트 통과)
  - `ruff check .` 및 `mypy .` 무결성 검증 (0 issues)
  - `./scripts/smoke_test.sh` 라이브 API 검증 통과
  - Cloudflare Tunnel 라이브 HTTPS 모바일 뷰포트 응답 검증 완료
