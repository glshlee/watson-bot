# ADR-043: 과거 라이프로그·GTD 고속 검색 및 주간 결산 회고 리포트 (`/search`, `/weekly`)

## 1. 컨텍스트 및 배경 (Context & Problem Statement)
일일 로그(`logs/daily/YYYY-MM-DD.md`)와 GTD 수집함(`gtd/inbox.md`, `next_actions.md`)에 일상, 생각, 업무, 운동 기록이 장기간 누적되고 있으나, 지금까지는 당일 기록과 실시간 GTD 목록 위주로만 열람할 수 있었습니다.
기록의 가치를 극대화하기 위해서는:
1. **과거 회상 및 탐색(Search)**: "지난달 서산 갔을 때 어디 갔었지?", "미역국 언제 끓였더라?" 등 특정 일상, 맛집, 아이디어를 수초 내에 찾아내고 문맥 스니펫을 제시하는 검색 엔진이 필요합니다.
2. **주간 결산 및 회고(Weekly Review)**: 매주 일요일 저녁 한 주간의 기록 달성률(7일 중 N일 기록), 완료한 GTD 태스크(- [x]), 카테고리별 활동(운동, 업무, 생각)을 종합 집계하고, 수집함에 장기 체류 중인 태스크를 정리하도록 권유하는 비서의 능동적 피드백이 필요합니다.

## 2. 의사결정 (Decision Drivers & Architecture)

### 1) 고속 전문 검색 엔진 (`SearchService` - `app/services/search_service.py`)
* **다중 디렉토리 스캔**:
  * 최우선 순위: `logs/daily/*.md` (파일명 기반 KST 일자 역순 정렬).
  * 2순위: `gtd/*.md` (`inbox.md`, `next_actions.md`, `projects.md` 등).
  * 3순위: 추가 마크다운 폴더 (`01_work`, `02_personal`, `03_side_projects`).
* **공백 구분 다중 키워드 AND 검색**:
  * "서산 어죽" 입력 시 동일 라인 또는 섹션 내에 "서산"과 "어죽"이 모두 포함된 행을 정확히 필터링.
* **마크다운 볼드 하이라이트 & 문맥 스니펫**:
  * 검색된 텍스트 주변을 적절한 길이(최대 220자)로 트리밍하고 일치 키워드를 `**키워드**`로 강조.
* **관련도 스코어링 & 정렬**:
  * 완전 일치, 일일 로그 최신성(최근 30일 가산점), GTD 수집함 가중치를 조합하여 가장 유의미한 상위 N건(기본 10건) 추출.

### 2) 주간 결산 회고 엔진 (`WeeklyReviewService` - `app/services/weekly_review_service.py`)
* **정량 메트릭 수집**:
  * 기준일(KST 오늘)로부터 과거 7일간의 일일 로그를 순회 파싱.
  * 기록 달성률 (`recorded_days / 7 * 100%`).
  * 완료 태스크 (`- [x]`) 일자별 수집 및 전수 카운트.
  * 섹션 우선 카테고리 분류 (🏃 운동, 💻 업무, 💡 생각/메모, 📝 일상).
* **GTD 수집함(Inbox) 체류 점검**:
  * `gtd/inbox.md`의 미분류 태스크(`- [ ]`) 목록을 읽어 개수를 보고하고, `next_actions.md` 배치 및 정리 가이드 제시.
* **하이브리드 주간 회고 한마디 합성**:
  * LLM(Gemini / AGY) 가용 시 한 주의 노고를 인정하고 격려하는 따뜻한 비서 총평 생성.
  * 외부 API 장애 또는 오프라인 시 기록 달성률과 완료 과제 수에 기반한 정교한 룰 기반 총평 자동 생성.

### 3) 일요일 21:00 KST 능동 푸시 스케줄러 (`BriefingScheduler`)
* 기존 아침(08:30 KST) 및 저녁(20:00 KST) 스케줄러 루프에 **매주 일요일 21:00 KST** 주간 결산 발송 루프 추가 (`now.weekday() == 6 and now.hour == 21 and now.minute == 0`).
* 중복 발송 방지 플래그(`self.last_dispatched["weekly"] = today_str`) 적용.
* 발송 시 인라인 액션 키보드(`[📥 Inbox 정리하기]`, `[⏳ D-Day 확인]`, `[🔄 원격 최신화]`, `[🚀 푸시]`) 부착.

### 4) REST API 엔드포인트 지원 (`app/routers/web_router.py`)
* `GET /api/search?q=키워드&limit=10`: 검색 결과 목록 및 마크다운 카드 JSON 반환.
* `GET /api/weekly?days=7`: 7일간 결산 메트릭스 및 주간 회고 마크다운 반환.
* `POST /api/weekly/trigger-push`: 텔레그램 주간 결산 즉시 푸시 테스트.

### 5) 텔레그램 및 웹 UI 연동
* 텔레그램 네이티브 봇 메뉴에 `search`, `weekly`를 추가하여 총 17종 기본 명령어 지원.
* 웹 대시보드 콘솔 왓슨 및 DevBot 퀵 숏컷 바에 `[🔍 기록 검색]` 및 `[📊 주간 결산]` 원터치 칩 탑재.

## 3. 결과 및 영향 (Consequences)
* **긍정적 영향**:
  * 과거 수개월 치 일기 속에 묻혀 있던 소중한 추억, 맛집, 결정, 아이디어를 `/search` 한 번으로 즉시 발굴.
  * 매주 일요일 밤 왓슨의 정량적 리포트와 따뜻한 총평으로 일주일을 보람차게 결산하고 다음 주를 준비하는 루틴 형성.
  * 수집함에 방치된 태스크가 누적되는 GTD 부채를 자연스럽게 정리 유도.
* **테스트 및 검증**:
  * 단위 테스트 (`tests/test_search_and_weekly_service.py`, 4종 테스트 전체 통과)
  * Ruff 및 Mypy 정적 검사 무결점 통과
  * cURL 라이브 스모크 테스트 (`scripts/smoke_test.sh` 3-13-9 ~ 3-13-15 전체 통과)
