# ADR-003: AGY AI Agent 자율 파일 조작 및 브릿지 아키텍처 전면 전환

* **상태 (Status)**: 승인됨 (Accepted)
* **날짜 (Date)**: 2026-08-29
* **작성자 (Author)**: Watson Core Team

---

## 1. 맥락 (Context)
기존 방식에서는 파이썬 백엔드가 마크다운 파싱, 수동 파일 덧붙이기, Git 커밋을 대신 수행하고 AI는 단발성 텍스트만 리턴하는 수동적인 구조였다.
이는 유저가 기대하는 "AGY AI 에이전트가 라이프 로그 마크다운 파일들을 직접 읽고 판단하여 작성/편집하고 커밋까지 자율 수행하는 시스템"의 본질에 부합하지 않았다.

---

## 2. 의사결정 (Decision)

### 2.1. AGY Agent Direct Execution (AGY 자율 실행 엔진)
* 파이썬 백엔드의 수동 텍스트 조작 로직을 제거하고, **AGY CLI (`/Users/glshlee/.local/bin/agy`)** 프로세스를 브릿지(Runner)로 호출한다.
* AGY 에이전트에게 워크스페이스 지침과 유저 메시지를 전달하여, **AGY 에이전트 본체가 직접 파일(`lifelogs/YYYY/MM/YYYY-MM-DD.md`)을 읽고, 작성하며, 필요시 Git 커밋/푸시 커맨드를 자율 실행**하도록 시스템을 전면 개편한다.

### 2.2. 브릿지 역할 (Watson Agent Bridge)
* 파이썬 백엔드는 유저(웹/텔레그램) ↔ AGY 에이전트 간의 **세션 통신 중계기(Bridge) 및 DB 대화 이력 기록자** 역할만 수행한다.

---

## 3. 결과 및 영향 (Consequences)

### Positive (긍정적 영향)
* **진짜 AI 에이전트 동작**: AGY 에이전트가 마크다운 템플릿의 양식과 상황을 직접 판단하여 마크다운 파일 생성/편집을 능동적으로 집행함.
* **유연성 극대화**: 무작위 입력 메시지에 대해 AGY가 적절한 마크다운 구조화 및 커밋 메시지를 자유롭게 판단함.

### Negative / Risk (주의사항)
* AGY CLI subprocess 실행 시 수초 간의 에이전트 판단 시간이 소요됨 ➔ 웹 UI 상에서 스피너 인디케이터 처리.
