# ADR-005: 24/7 상시 가동을 위한 Docker 컨테이너 패키징 및 볼륨 영속화

* **상태 (Status)**: 승인됨 (Accepted)
* **날짜 (Date)**: 2026-09-05
* **작성자 (Author)**: Watson Core Team & User

---

## 1. 맥락 (Context)
Watson 애플리케이션을 원격 서버(클라우드 VPS, 홈 서버 등) 환경에서 24시간 365일 무중단으로 안정적으로 운영하기 위해서는:
1. 호스트 OS 및 파이썬 런타임 환경에 구애받지 않는 독립된 표준 런타임이 필요함.
2. 서버 재부팅 또는 프로세스 비정상 종료 시 자동 재시작(`restart: always`)이 보장되어야 함.
3. 컨테이너가 재생성되더라도 대화 히스토리 DB(`app.db`)와 라이프로그 마크다운 파일(`lifelogs/`)이 영구 보존되는 볼륨 마운트 구조가 필요함.
4. 컨테이너 내부에서 GitHub 원격 저장소로의 Git 자동 푸시가 원활히 동작해야 함.

---

## 2. 의사결정 (Decision)

### 2.1. 표준 경량 컨테이너 이미지 (`Dockerfile`)
* **베이스 이미지**: `python:3.11-slim`을 채택하여 x86_64 및 ARM64(오라클 Ampere 등) 멀티 아키텍처 호환성과 최소화된 이미지 크기를 달성한다.
* **필수 시스템 패키지**: 마크다운 Git 자동화를 위한 `git`, `curl`을 베이스 단계에서 설치한다.
* **실행 명령**: `uvicorn app.main:app --host 0.0.0.0 --port 8000`

### 2.2. 볼륨 영속화 및 오케스트레이션 (`docker-compose.yml`)
* **호스트 볼륨 매핑**:
  * `./app.db:/app/app.db`: SQLite 세션 DB 영속화
  * `./lifelogs:/app/lifelogs`: 날짜별 마크다운 라이프로그 영속화
  * `~/.gitconfig` 및 `~/.ssh:/root/.ssh:ro`: 호스트의 Git 인증 정보 안전 공유
* **자동 복구 정책**: `restart: always`를 적용하여 장애 시 자동 복구.
* **환경변수 분리**: `.env` 파일을 통해 `GEMINI_API_KEY`, 포트, Git 설정을 외부 주입.

### 2.3. 비-도커(Non-Docker) 환경을 위한 systemd 데몬 병행 제공
* 도커를 사용하지 않는 경량 리눅스 환경을 위해 `systemd/watson.service` 유닛 파일도 함께 제공한다.

---

## 3. 결과 및 영향 (Consequences)

### Positive (긍정적 영향)
* **환경 독립성**: 어떤 클라우드나 온프레미스 서버에서도 `docker compose up -d` 명령어 하나로 10초 만에 완벽 기동.
* **무중단 안정성**: 서버 크래시나 재부팅에도 무인 자동 복구 보장.
* **데이터 무결성**: 컨테이너 업데이트 및 재배포 시에도 라이프로그와 세션 DB 완벽 보존.
