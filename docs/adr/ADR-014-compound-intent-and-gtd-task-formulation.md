# ADR-014: 복합 의도 감지(데일리 로그 + GTD 인박스 동시 기록) 및 태스크 정제

## 1. 배경 (Context)
사용자가 "로그와 gtd에 기록해줘", "일기랑 할일에 추가해줘"와 같이 한 문장에 서사적 일상 일기(Daily Journal)와 실행 가능한 태스크(GTD Next Action/Inbox)를 동시에 요구하는 경우가 발생하였다.
기존 시스템에서는 다음과 같은 결함이 발견되었다:
1. **단일 의도 배타적 라우팅 결함**: 카테고리가 `gtd_task_categories`에 속하면 GTD 인박스에만 기록하고 데일리 로그를 무시하거나, 반대로 데일리 로그에만 기록하고 GTD 인박스를 누락함.
2. **지시어 접미사 누출 (Suffix Leakage)**: 정규식 `(.*?)기록해줘(.*)`로 인해 "로그와 gtd에" 같은 명령어 수식어 및 마침표(`.`)가 본문 끝에 잔존(`...게국지 집에도 가보고싶대. 로그와 gtd에 .`)하여 일기 품질 저하.
3. **태스크 정제 부재 (Raw Diary Dumping)**: 장문의 일상 사연 전체가 GTD 인박스에 그대로 투입되거나 포맷팅 없이 방치되어 실행 가능한 할 일(Actionable Task)의 성격을 상실함.
4. **GTD 섹션 매핑 부재**: 인박스의 대주제 섹션(`## 🧘 개인 생활 & 건강 (02_personal)`, `## 🏢 회사 업무 (01_work)`)을 식별하지 못해 태스크가 엉뚱한 위치에 삽입될 위험 존재.

## 2. 결정 사항 (Decision)
1. **복합 의도(`log_dual`) 식별 및 깔끔한 접미사 제거 (`LLMProvider`)**:
   - `IntentResult`에 `gtd_task_content: str | None = None` 및 `is_dual_log: bool = False` 속성 추가.
   - `dual_pattern`(`r"(?:(.*?)[\s,\.]*)?(?:로그(?:와|랑)|일기(?:와|랑))\s*(?:gtd|할일|태스크)(?:에|도)?\s*기록해줘"`) 및 역순 패턴(`dual_reverse_pattern`)을 통해 복합 요청을 감지.
   - 문장 말미의 지시어("로그와 gtd에 기록해줘") 및 불필요한 문장부호/공백을 완벽히 절삭하여 순수한 서사 본문만 추출.
2. **경량 휴리스틱 태스크 정제 엔진 (`_extract_actionable_task`)**:
   - 외부 LLM 지연이나 타임아웃 위험 없이 여행, 맛집, 업무, 구매, 건강 등 서사 내용에서 핵심 키워드(목적지, 식당/장소명, 행동 동사)를 고속 추출하여 행동 지향적 태스크 포맷(`- [ ] 서산 여행 계획 및 맛집 방문 (용현집 어죽, 또간집 게국지) 🚗🍲`)으로 합성.
3. **스마트 도메인 섹션 라우팅 (`AgentService.append_to_gtd_inbox`)**:
   - `inbox.md` 내부의 `## 🏢 회사 업무 (01_work)`, `## 🧘 개인 생활 & 건강 (02_personal)` 등 마크다운 헤더를 문맥 기반으로 탐색하여 적절한 섹션 하단에 태스크 자동 배치 (매칭 실패 시 파일 말미 또는 Quick Capture로 안전 폴백).
4. **단일 트랜잭션 동시 반영 및 Git 커밋 (`SupervisorService`)**:
   - `log_dual` 인텐트 수신 시 ① 데일리 로그에 정제된 일상 서사 기록 ➔ ② GTD 인박스에 정제된 액션 태스크 기록 ➔ ③ 변경된 두 파일을 단일 커밋(`📝 Dual Log: Daily entry & GTD task captured`)으로 원자적 Git 동기화.
5. **라이브 데이터 정정**:
   - `life_log/logs/daily/2026-09-08.md`의 잔존 지시어(". 로그와 gtd에 .")를 정제하고, `life_log/gtd/inbox.md`의 `## 🧘 개인 생활 & 건강` 섹션에 정제된 서산 여행 태스크를 소급 추가.

## 3. 결과 및 영향 (Consequences)
- **장점**:
  - 단 한 번의 자연스러운 대화로 일기 회고와 GTD 태스크 수집이 누락 없이 동시에 완결.
  - 지시어 잔여물이 완전히 제거되어 깔끔한 일기 마크다운 유지.
  - GTD 인박스에 실행 가능한 고품질 태스크가 카테고리별로 정갈하게 적재.
- **테스트 및 검증**:
  - `tests/test_llm_provider.py`: 복합 의도 감지, 지시어 제거, 태스크 추출 단위 테스트 통과.
  - `tests/test_agent_service.py`: GTD 스마트 섹션 라우팅 단위 테스트 통과.
  - `tests/test_supervisor_service.py`: 데일리 로그 + GTD 인박스 동시 기록 파이프라인 E2E 테스트 통과.
  - `./scripts/smoke_test.sh`: 3-8 복합 의도 cURL 라이브 API 검증 통과 (전체 스모크 테스트 성공).
