# ADR-007: GTD/라이프로그 외부 저장소 디렉토리 동적 지정 및 기능 오케스트레이션 아키텍처

* **상태 (Status)**: 승인됨 (Accepted)
* **날짜 (Date)**: 2026-09-08
* **작성자 (Author)**: Watson Core Team & User

---

## 1. 맥락 (Context)
기존 Watson 시스템은 라이프로그 마크다운 및 미디어 파일을 봇 엔진 자체의 소스코드 저장소(`watson-bot/lifelogs`) 내부에 기록하고 커밋해왔다.
그러나 소스코드 레포지토리와 사용자의 개인 프라이빗 데이터(GTD 할 일, 일기, 건강 메모 등)를 함께 관리하는 것은 버전 관리, 보안, 데이터 격리 측면에서 바람직하지 않다.
또한 사용자는 이미 자체적인 GTD 체계(`gtd/inbox.md`, `gtd/next_actions.md`, `logs/daily/` 등)를 갖춘 독립 Git 저장소(예: `workspace/life_log`)를 운용하고 있다.
따라서 Watson은 봇 엔진 코드베이스와 데이터를 완벽히 분리하고, 웹 대시보드 UI 및 설정을 통해 GTD 디렉토리 경로를 동적으로 지정받아 해당 저장소의 체계를 있는 그대로 활용하며 기능들을 지능적으로 오케스트레이션해야 한다.

---

## 2. 의사결정 (Decision)

### 2.1. 동적 GTD 경로 설정 관리 (`SettingsService` & API)
* 웹 대시보드 UI 설정 및 REST API (`GET/POST /api/settings/gtd-path`)를 통해 GTD 작업 디렉토리 경로를 동적으로 조회하고 즉시 변경할 수 있도록 한다.
* 설정 우선순위:
  1. 동적 설정 저장소 (`app/config/gtd_config.json` 또는 SQLite)
  2. 환경 변수 (`.env`의 `GTD_PATH`)
  3. 기본값 폴백: 하위 호환성을 위해 미지정 시 기존 로컬 경로(`.` / `lifelogs/`) 유지
* 경로 변경 시 대상 디렉토리 유효성 및 권한을 실시간 검증하고 결과를 반환한다.

### 2.2. 독립 GTD 레포지토리 Git 격리 (Git Isolation)
* 지정된 GTD 디렉토리에 `.git`이 존재하는 경우: `GitService(repo_path=gtd_path)`를 생성하여 **GTD 디렉토리의 전용 Git 저장소에 독립적으로 커밋 및 푸시**를 집행한다. 왓슨 소스코드 레포지토리(`watson-bot`)는 완전히 무결하게 유지된다.
* 지정된 디렉토리에 `.git`이 없는 경우: Git 오류 없이 로컬 마크다운 파일로만 안전하게 저장한다 (`local-only` 모드).

### 2.3. 외부 저장소 GTD 체계 오케스트레이션 (GTD Orchestration)
* 대상 저장소에 기정의된 체계가 존재할 경우 이를 그대로 존중하여 오케스트레이션한다:
  * **GTD 수집함(`inbox.md`) 감지**: 대상 디렉토리에 `gtd/inbox.md`가 존재하면, 할 일/메모/캡처 요청 시 해당 파일의 `## 💬 빠른 메모 / 캡처` 섹션에 체크박스(`- [ ] ...`) 형식으로 스마트하게 추가한다.
  * **일자별 라이프로그 감지**: `logs/daily/YYYY-MM-DD.md` 구조가 존재하면 해당 경로를 우선 사용하고, 없으면 표준 `lifelogs/YYYY/MM/YYYY-MM-DD.md` 구조를 생성한다.
* 왓슨은 데이터를 강제로 변환하지 않고 해당 레포지토리의 GTD 규칙에 맞춰 작업을 오케스트레이션하는 데 집중한다.

### 2.4. 웹 대시보드 UI 설정 지원
* 웹 대시보드 상단/설정 영역에 현재 연결된 GTD 디렉토리 경로와 Git 연동 여부(`Git Active` / `Local Only`) 배지를 표시한다.
* 대시보드에서 새로운 디렉토리 경로를 입력하고 원클릭으로 연결을 전환할 수 있는 UI를 제공한다.

---

## 3. 결과 및 영향 (Consequences)

### Positive (긍정적 영향)
* **완벽한 데이터 격리**: 소스코드 저장소(`watson-bot`)와 개인 라이프 데이터가 완벽하게 분리되어 코드 공유 및 배포 시 프라이버시가 100% 보장됨.
* **기존 자산 무손실 연동**: 이미 사용자가 운용 중인 옵시디언/GTD 레포지토리의 체계를 변경 없이 즉시 연동하여 비서로 활용 가능.
* **유연한 운영**: 웹 UI에서 실시간으로 대상 작업 경로를 전환 가능하며, 환경 변수 및 파일 영속화로 컨테이너/데몬 환경에서도 안정적 유지.
