# ADR-017: 웹 UI 세션 관리 고도화 (이름 변경, 검색, 필터링, 삭제 및 스마트 제목)

## 1. 배경 (Context)
Watson의 웹 콘솔은 다중 대화 세션을 지원하였으나, 세션 목록 UI가 단순 리스트 나열 수준에 머물러 있었다.
이로 인해 다음과 같은 사용자 불편이 발생하였다:
1. **세션 식별 및 네이밍 부재**: 새 세션 시작 시 `web_session_1725...` 또는 `New Conversation` 같은 무의미한 ID/기본명으로만 표시되어 이전 대화 주제를 찾기 어려움.
2. **세션 편집/삭제 불가능**: 불필요한 테스트 세션이나 완료된 대화를 삭제할 수 없고, 세션 이름을 원하는 주제(예: "서산 여행 계획", "운동 일지")로 변경할 수 없음.
3. **세션 탐색 및 필터링 부재**: 세션이 많아졌을 때 키워드로 검색할 수 없고, 웹 콘솔 세션과 텔레그램 연동 세션을 분리해서 볼 수 없음.
4. **세션 메타데이터 미표시**: 메시지 개수, 최근 대화 시간, 최근 메시지 요약 등이 노출되지 않아 세션의 최신 상태 파악 불가.

## 2. 결정 사항 (Decision)
1. **세션 관리 REST API 확장 (`app/routers/web_router.py`)**:
   - `PATCH /api/sessions/{session_id}`: 세션 제목 수정 API 구현 (`UpdateSessionRequest(title: str)`).
   - `DELETE /api/sessions/{session_id}`: 세션 및 연결된 모든 메시지 캐스케이드 삭제 API 구현.
   - `POST /api/sessions/{session_id}/clear`: 세션 메타데이터는 유지하고 메시지 히스토리만 비우는 API 구현.
   - `GET /api/sessions`: `id`, `title`, `channel`, `created_at`, `updated_at`, `message_count`, `last_message` 등 풍부한 메타데이터 반환.
2. **스마트 제목 자동 생성 (Smart Auto-Naming - `SessionService`)**:
   - 사용자가 새 세션에서 첫 메시지를 발화했을 때, 기본 제목인 경우 첫 메시지의 핵심 요약(26자 이내)으로 세션 제목을 자동 부여하여 ChatGPT/Claude 수준의 자연스러운 세션 관리 제공.
3. **고도화된 세션 관리 웹 UI (`index.html`, `style.css`, `main.js`)**:
   - **실시간 검색 필터**: 검색창에 키워드 입력 시 제목, 세션 ID, 최근 메시지 내용을 실시간 필터링.
   - **채널 필터 탭**: `전체(All)`, `🌐 웹(Web)`, `📱 텔레그램(Telegram)` 탭으로 세션 분리 조회.
   - **세션 리치 카드**: 채널 뱃지(웹/텔레그램), 세션명, 상대 시간("방금", "5분 전", "어제"), 메시지 개수 뱃지 표시.
   - **세션 액션 메뉴 & 모달**: ✏️ 이름 수정 모달, 🗑️ 삭제 확인 모달, 🧹 대화 비우기 모달을 통해 안전한 CRUD 제공. 활성 세션 삭제 시 인접 세션으로 자동 전환.
   - **상단 헤더 연동**: 채팅창 상단에 현재 활성 세션의 제목과 상세 메타데이터(채널 구분, 메시지 개수) 실시간 표시.

## 3. 결과 및 영향 (Consequences)
- **장점**:
  - 세션 주제별 체계적 정리 및 검색을 통해 일상/업무 라이프로그 대화의 가독성과 생산성 대폭 향상.
  - 텔레그램 세션과 웹 세션을 명확히 구분하여 멀티채널 대화 히스토리 탐색 가능.
  - UI 상에서 간편하게 세션 이름을 변경하고 정리할 수 있어 관리 편의성 극대화.
- **검증**:
  - `pytest tests/test_session_service.py tests/test_web_router.py`: 세션 라이프사이클 및 CRUD 엔드포인트 6개 테스트 100% 통과.
  - `mypy .` 및 `ruff check .`: 정적 타입 및 린트 검사 무결점 통과 (26개 소스 파일).
  - `./scripts/smoke_test.sh`: 라이브 cURL 스모크 테스트 100% 통과.
  - 라이브 cURL API 검증: PATCH(수정), POST(비우기), DELETE(삭제) 정상 응답 검증 완료.
