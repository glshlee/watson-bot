# 📋 Watson (GitHub LifeLog AI Agent) PRD (Product Requirement Document)

## 1. 제품 개요 (Product Overview)
* **제품명**: Watson (GitHub LifeLog AI Agent System)
* **목적**: 24시간 가동되는 개인 서버 환경에서 AI 에이전트를 상시 운영하여, 노트북/PC 연결 없이도 텔레그램 봇 및 웹 대시보드를 통해 언제 어디서나 삶의 기록(Life Log)을 마크다운(MD) 형식으로 작성, 수정, 관리하고 GitHub 레포지토리에 자동 커밋/푸시(Git Commit & Push)하는 자동화 시스템 구축.
* **핵심 타겟**: 
  * GitHub 마크다운 파일 기반으로 일기, 운동, 업무, 생각 등의 라이프 로그를 작성하는 유저.
  * 24시간 서버 환경을 통해 언제 어디서나 모바일/웹으로 AI 에이전트를 호출해 정제된 라이프 로그를 남기고자 하는 유저.

---

## 2. 핵심 비전 및 유저 경험 (User Experience Goals)
1. **Anytime, Anywhere Access (어디서나 접근성)**
   * 모바일에서는 텔레그램 봇으로 메시지/사진/음성 메모 송신 ➔ AI가 라이프로그 정제 후 GitHub 즉시 반영.
   * PC/모바일 브라우저에서는 웹 대시보드(Watson)로 월별/일별 라이프 로그 시각화 및 AI 대화형 편집.
2. **Seamless Git Automation (투명한 Git 자동화 & 1기록 1커밋 - ADR-004)**
   * 단순 잡담/질의는 커밋하지 않으며, 비서가 감지/제안하여 사용자가 승인했거나 직접 기록한 유의미한 라이프로그에 한해 즉시 `git commit` & `git push` 자동 집행.
   * 다중 세션(텔레그램, 웹) 간 데이터 정합성을 위해 확정된 기록 즉시 안전하게 원격 반영.
3. **Smart Lifelog Butler (비서형 상호작용 & 마크다운 구조화)**
   * 수동 명령어 없이도 대화 중 운동, 미팅, 생각 등 가치 있는 일과를 비서가 감지하여 자연스럽게 기록을 제안(Proactive Suggestion).
   * 무작위 메모도 AI가 템플릿(일기, 운동 기록, 감상평, 캘린더 등)에 맞춰 일관성 있게 구조화된 MD로 작성.

## 3. 주요 기능 명세 (Key Features)

### 3.1. 🤖 AI 에이전트 코어 (Agent Core Engine)
* **Smart Lifelog Butler & Intent Router (지능형 비서 및 의도 분리기)**:
  * 대화 입력 시 [단순 잡담/질의], [일과 감지 및 기록 제안], [제안 승인], [직접 명령]을 자동 판별.
  * 제안된 후보(`pending_log`)를 세션 맥락에 보관하고, 승인 시 마크다운 반영 및 Git 커밋 파이프라인 트리거.
* **LifeLog Generator**: 입력된 메시지/데이터를 날짜별(`YYYY-MM-DD.md` 또는 `year/month/day.md`) 양식에 맞춰 변환/업데이트.
* **Git Operations Worker**: 백그라운드에서 repository pull ➔ MD 파일 변경 ➔ commit (`docs(lifelog): [카테고리] 요약 - YYYY-MM-DD`) ➔ push 수행.
* **Session & Context Management (다중 세션 대화 맥락 관리)**: 
  * 세션 ID 기반 대화 히스토리 및 맥락(Context Memory), 임시 기록 후보(`pending_log`) 영속적 유지.
  * 동일 세션 내 이전 대화 내용 및 대상 MD 파일 상태를 AI가 인지하여 자연스러운 연속 대화 및 덧붙이기(Append/Edit) 수행.
  * 텔레그램 채널별/웹 대시보드 대화방별 멀티 세션 독립 관리.

### 3.2. 💬 텔레그램 봇 인터페이스 (Telegram Bot Interface)
* `/log [내용]`: 라이프 로그 바로 기록.
* `/summary`: 최근 기록 요약 및 이번 주/달 분석 리포트 제공.
* `/status`: Git 서버 상태 및 최근 커밋 확인.
* 사진/이미지 및 메모 수신 시 AI 처리 후 적절한 MD 경로에 매핑 저장.

### 3.3. 🌐 웹 대시보드 (Web Dashboard - Watson)
* **대시보드 메인**: 최근 활동 스트림, 최근 깃 커밋 내역, 이번 달 라이프 로그 달력(Calendar View).
* **MD 라이프 로그 뷰어 & 에디터**: 렌더링된 마크다운 보기 및 실시간 수동 수정 기능.
* **에이전트 대화창**: 웹상에서 AI 에이전트와 직접 상호작용하며 라이프 로그 추가/질의응답/재정리 요청.

### 3.4. 📁 GTD 저장소 격리 및 동적 오케스트레이션 (GTD Directory Orchestration - ADR-007)
* **저장소-엔진 관심사 분리**: 왓슨 봇 소스코드 저장소와 개인 GTD/라이프로그 데이터를 완전히 분리.
* **동적 디렉토리 지정**: 웹 대시보드 UI 및 REST API(`GET/POST /api/settings/gtd-path`)를 통해 작업 GTD 디렉토리를 동적으로 변경/연결.
* **외부 GTD 체계 적응 및 오케스트레이션**: 연결된 레포지토리의 GTD 구조(`gtd/inbox.md`, `logs/daily/` 등)를 자동 감지하고 수집함 및 일일 로그에 맞춰 지능적 캡처/기록 오케스트레이션 수행.
* **독립 Git 격리**: 연결된 GTD 디렉토리가 독립 Git 레포지토리일 경우 해당 레포로만 커밋/푸시하고, 일반 디렉토리일 경우 로컬 파일로 안전하게 관리.

### 3.5. 📋 GTD 지능형 브리핑 및 일정 요약 (Task Briefing - ADR-008)
* **할 일/일정 실시간 조회**: 사용자가 "오늘 해야 할 일 정리해줘", "투두 목록", "일정 알려줘" 요청 시 GTD 저장소(`logs/daily/`, `gtd/next_actions.md`, `gtd/inbox.md`)를 즉시 파싱하여 종합 브리핑 제공.
* **Linux 환경 AGY CLI 100% 가동**: 백그라운드 데몬 및 리눅스 환경에서도 AGY 인텔리전스를 완전히 가동하여 자연스러운 대화 맥락 유지.

### 3.6. 🔄 GTD 저장소 원격 동기화 및 자동 Pull (Repo Sync - ADR-009)
* **온디맨드 레포 최신화**: 사용자가 "gtd 레포 최신화하고 다시 알려줘", "레포 최신화", "/sync" 요청 시 원격 GitHub로부터 최신 커밋을 `git pull --rebase --autostash`로 안전하게 동기화한 후 최신 상태 브리핑 제공.
* **브리핑 시 자동 최신화**: 할 일/일정 브리핑 요청 시 원격 저장소와 자동 동기화하여 멀티 디바이스(옵시디언, 모바일 등) 작업 내역 실시간 반영.

### 3.7. 🧠 세션 맥락 참조 기록 및 프롬프트 경량화 (Context-Aware Logging - ADR-010)
* **대화 맥락 참조 기록**: "아까 말한 내용도 기록해줘", "방금 이야기 일기에 적어줘" 등 이전 대화 맥락을 가리키는 요청 시 세션 히스토리에서 사용자 발화를 역추적하여 대상 마크다운 파일에 즉시 영속화 및 Git 커밋.
* **멀티라인 명령 수용 및 AGY 경량화**: 줄바꿈 및 복합 설명문이 포함된 입력을 안정적으로 파싱하고, 히스토리 토큰 경량화 및 타임아웃 50초 확장으로 지속적인 세션 대화 무결성 유지.

### 3.8. 🚀 결정론적 Git 푸시 및 AGY Headless 무중단 실행 (Repo Push - ADR-011)
* **결정론적 원격 푸시 의도 분기**: "푸시해줘", "푸시도 해줘", "깃 푸시", "/push", "푸시가 안됐는데 다시 확인해줘" 등 명시적 푸시 요청 시 LLM 환각(거짓말)을 차단하고 백엔드 `GitService.push()`를 즉시 실행하여 실시간 상태 보고.
* **Autostash 안전 병합 및 동기화 격리**: 로컬 작업 트리에 수정/언스테이징 파일이 있더라도 `autostash`를 통해 안전하게 병합 후 푸시 집행.
* **AGY Headless 권한 자동 승인**: `--dangerously-skip-permissions` 플래그 및 프롬프트 가드레일을 적용하여 비대화형 CLI 권한 거부 오류와 엉뚱한 폴백 표출을 원천 방지.

### 3.9. 🛡️ 테스트 샌드박스 격리 및 대화형 지시어 문맥 역추적 (Test Sandbox & Directive Resolution - ADR-012)
* **테스트 샌드박스 완벽 격리**: cURL 스모크 테스트 실행 시 임시 Git 저장소 샌드박스를 구성하여 테스트 더미 데이터가 사용자의 실제 개인 GTD 저장소에 유입되는 것을 100% 원천 차단.
* **구어체 지시어 문맥 역추적**: "응 오늘 로그에 기록해줘", "오늘 일기에 적어줘", "응 기록해줘" 등 지시어만 존재하는 요청 시 지시어 문구를 본문으로 오인하지 않고, 세션 히스토리에서 직전 나눈 긴 사연/감정을 역추적하여 안전하게 기록.

### 3.10. ⏱️ 한국 표준시(KST) 타임존 로컬라이제이션 (Timezone Localization - ADR-013)
* **KST(Asia/Seoul, UTC+9) 전면 동기화**: 서버의 기본 시간대(UTC)와 무관하게 모든 일일 로그 파일 경로(`YYYY-MM-DD.md`), 일기 기록 타임스탬프(`[HH:MM]`), 커밋 메시지 일자, 텔레그램 동기화 시간 및 브리핑을 한국 표준시로 정규화.
* **자정 경계(Midnight Boundary) 오류 원천 방지**: 한국 시각 기준 자정(00:00)부터 오전 09:00 사이 기록 시 UTC의 전날 날짜로 잘못 분기되는 결함을 완전히 차단하고 당일 일일 로그에 정상 기록.
* **환경 변수 기반 유연성**: `.env`의 `TIMEZONE` 설정을 통해 향후 글로벌 시간대 지원 및 다중 사용자 시간대 확장성 확보.

### 3.11. 🧭 복합 의도 감지 및 GTD 태스크 정제 (Compound Intent & Task Formulation - ADR-014)
* **데일리 로그 + GTD 동시 라우팅**: "로그와 gtd에 기록해줘", "일기랑 할일에 적어줘" 등 듀얼 요청 수신 시, 서사적 일기는 데일리 저널(`logs/daily/YYYY-MM-DD.md`)에, 실행 가능한 할 일은 GTD 인박스(`gtd/inbox.md`)에 단일 트랜잭션으로 동시 기록.
* **지시어 접미사(Suffix Leakage) 원천 차단**: 문장 끝부분의 지시어 수식구("로그와 gtd에 기록해줘") 및 구두점을 완벽히 절삭하여 깔끔한 일기 본문 보존.
* **행동 지향적 태스크 고속 정제**: 비정형 일기 사연 전체를 인박스에 복사하지 않고, 여행지/맛집/업무/구매 등의 핵심 요소를 추출하여 실행 가능한 포맷(`- [ ] 서산 여행 계획 및 맛집 방문 (용현집 어죽, 또간집 게국지) 🚗🍲`)으로 합성 및 적절한 도메인 섹션(`## 🧘 개인 생활 & 건강`)에 자동 배치.

### 3.12. 🔐 웹 콘솔 보안 인증 및 Cloudflare Tunnel 외부 연동 (Web Auth & Tunnel - ADR-015)
* **HTTP Basic 보안 인증 (ID/PW 가드)**: 브라우저 접속 시 네이티브 로그인 팝업을 통해 인가된 사용자만 웹 콘솔(`/`, `/api/*`)에 접근하도록 보호하여, 개인 일기와 GTD 태스크의 외부 유출 및 임의 조작 원천 차단.
* **무개방 Cloudflare Tunnel & 자동 HTTPS**: 클라우드 인바운드 방화벽 포트를 외부에 열지 않고 아웃바운드 터널로 암호화 연결을 생성하며, 무료 SSL(HTTPS) 인증서 기반으로 어디서나 모바일/PC 브라우저에서 안전 접속 보장.
* **무중단 systemd 백그라운드 구동**: `watson-tunnel.service`를 통해 왓슨 서비스와 함께 24/7 상시 터널링 가동.

### 3.13. 📱 모바일 퍼스트 반응형 웹 인터페이스 & 터치 최적화 (Mobile-First Responsive Web UX - ADR-016)
* **오프캔버스 드로어 & 모바일 햄버거 메뉴**: 스마트폰/태블릿 화면 폭(<= 768px)에서 사이드바를 슬라이드 드로어로 자동 전환하여 채팅 화면을 100% 확보하고, 세션 선택 및 새 세션 시작 시 드로어 자동 닫힘 제공.
* **동적 뷰포트(100dvh) 및 가상 키보드 최적화**: 모바일 브라우저 주소창 및 가상 키보드 팝업 시 레이아웃 깨짐을 방지하고, 16px 폰트 설정으로 iOS 사파리 자동 확대(Auto-zoom) 차단.
* **터치 친화적 UI 컴포넌트**: 모바일 헤더 축약 타이틀, GTD 배지 말줄임, 최소 38px~44px 터치 타깃 빠른 액션 버튼 및 자동 리사이징 텍스트에어리어 적용.

### 3.14. 🗂️ 웹 콘솔 세션 관리 고도화 (Advanced Session Management UI - ADR-017)
* **실시간 세션 검색 및 채널별 필터링**: 세션 제목, 고유 ID, 최근 메시지 내용을 기준으로 실시간 클라이언트 사이드 키워드 검색을 지원하고, `전체` / `🌐 웹` / `📱 텔레그램` 탭을 통한 채널별 원클릭 필터링 제공.
* **세션 제목 변경 (인라인/모달 편집)**: 직관적인 모달 대화창을 통해 세션 이름을 원하는 명칭으로 자유롭게 수정하고 실시간 UI 및 SQLite DB에 영속화.
* **세션 삭제 및 안전 폴백**: 특정 세션 및 하위 대화 메시지를 원자적으로 삭제하며, 현재 열린 세션 삭제 시 인접 세션 또는 기본 세션으로 안전하게 자동 전환.
* **대화 내역 비우기 (Clear Messages)**: 세션 메타데이터와 ID는 유지한 채 대화 메시지만 깔끔하게 초기화하여 새 대화 시작 지원.
* **첫 메시지 기반 자동 세션 네이밍**: 신규 세션에서 사용자가 첫 프롬프트를 전송하면 핵심 문구를 추출하여 가독성 높은 제목으로 자동 업데이트.
* **풍부한 세션 카드 및 헤더 메타 연동**: 메시지 개수, 상대적 경과 시간("방금", "5분 전", "어제"), 채널 배지를 표시하고, 헤더 영역에 활성 세션 정보 및 대화 비우기 바로가기 버튼 제공.

### 3.15. 🚀 에이전트 허브 대시보드 포털 및 개발 에이전트 분리 (Agent Hub & Dev Agent - ADR-018)
* **에이전트 허브 대시보드 포털 (`/`)**: 등록된 모든 AI 에이전트(Watson 비서, DevBot 개발자, 확장 슬롯)의 실시간 상태, 가동 지표, 주요 역량을 한눈에 모니터링하고 원클릭으로 전용 콘솔에 입장할 수 있는 상위 런처 포털 제공.
* **개발 전담 에이전트 DevBot 콘솔 (`/dev`)**: 소스코드 분석, Git 버전 관리(Status/Diff/Log/Branch) 빠른 실행 칩, 터미널 도구 자동화 및 기술 질의응답을 지원하는 전용 엔지니어링 콘솔 탑재.
* **왓슨 비서 콘솔 분리 (`/watson`)**: 일상 메모, 감정 회고, GTD 할 일 수집함 및 일정 브리핑을 담당하는 비서 콘솔을 독립 경로로 연결하고, 상단 헤더에 `[🏠 에이전트 허브]` 이동 링크 배치.
* **에이전트별 세션 및 역할 격리 (`agent_type`)**: SQLite `sessions` 테이블에 `agent_type` 컬럼을 도입하여 개인 일기/GTD 맥락과 개발 소스코드/Git 로그가 서로 간섭하지 않도록 물리적 격리 보장.

### 3.16. 🛠️ DevBot 대화형 엔지니어링 툴체인 및 실시간 개발 실행 환경 (Interactive Dev Toolchain - ADR-019)
* **대화형 엔지니어링 툴체인 단축 명령**:
  * `/test [경로]`: 터미널 접근 없이 DevBot 콘솔에서 pytest 단위 테스트를 즉시 실행하고 간결한 테스트 성공/실패/통계 브리핑 제공.
  * `/lint`: Ruff 정적 분석기 및 Mypy 타입 검사기를 병렬 실행하여 코드 무결성을 뱃지 형태로 보고.
  * `/commit [메시지]`: 현재 Git 워크스페이스의 변경점 및 diff를 분석하여 Conventional Commits 기반 추천 메시지 3종을 제안하거나 지정된 메시지로 즉시 안전 커밋 집행.
  * `/help`: 사용 가능한 모든 개발 툴체인 명령어 도움말 안내.
* **AGY CLI 호출 정규화 및 고탄력 엔지니어링 추론**:
  * 비대화형 실행 표준 인자(`-p "<prompt>" --dangerously-skip-permissions`), 50초 타임아웃, PATH 자동 보정 적용.
  * 워크스페이스 Git 상태, 브랜치, 변경 파일 수, 최근 커밋뿐 아니라 `docs/roadmap.md`의 최근 마일스톤 현황을 프롬프트 컨텍스트에 실시간 주입하여 살아있는 시니어 엔지니어 페어 프로그래밍 대화 제공.
* **웹 콘솔 UI 퀵 툴 칩 (Quick Action Chips)**:
  * `/dev` 웹 콘솔 하단 입력창 상단에 `/test`, `/lint`, `/commit`, `/help` 버튼을 배치하여 모바일/데스크톱 원터치 도구 실행 지원.
* **안전한 프로세스 격리 및 입력 인젝션 방지**:
  * 디렉토리 트래버설(`..`) 및 쉘 메타문자(`;`, `&`, `|`, `>` 등) 차단을 통해 외부 명령 인자 위변조 원천 차단.

### 3.17. 🛡️ 결정론적 GTD 태스크 삭제, 구어체 원격 푸시/커밋 라우팅 및 저장소 투명성 (Deterministic Task Removal & Git Transparency - ADR-020)
* **결정론적 GTD 태스크 삭제 (`gtd_remove`)**: "tiara_ad는 제거해", "주간보고 제거" 등 사용자 요청 시 실제 `gtd/inbox.md` 및 `gtd/next_actions.md` 파일에서 일치하는 태스크 라인을 찾아 물리적으로 안전하게 삭제하고, 원자적 Git 커밋/푸시 집행.
* **명시적 Git 커밋 명령 (`repo_commit`)**: "커밋해", "커밋", "/commit" 요청 시 실제 작업 트리 변경 상태를 검사하여 변경점이 있을 때만 커밋/푸시하고, 변경점이 없으면 "작업 트리가 깨끗합니다"라고 정직하게 안내.
* **구어체 원격 푸시 (`repo_push`) 및 저장소 정보 투명 브리핑**: "푸시도해야지", "푸시해야지", "올려야지" 등 한국어 구어체 어미를 전면 포괄하며, "어디다 푸시한거야?" 질문 시 실제 연결된 GitHub Remote URL(`https://github.com/...`)과 브랜치명, 최신 커밋 해시를 투명하게 제공하여 LLM 허위 환각(가상 브랜치 날조 등) 원천 차단.

### 3.18. 🌐 웹 연결 복원력, Cloudflare HTTP/2 터널 안정화 및 화면 복귀 자동 동기화 (Web Connection Resilience - ADR-021)
* **Cloudflare HTTP/2 전송 및 Uvicorn Keep-Alive 튜닝**:
  * `cloudflared` 통신 프로토콜을 QUIC UDP에서 TCP TLS 기반 HTTP/2로 강제하여 클라우드 NAT 게이트웨이 및 모바일 통신망의 무입력 포트 만료/유휴 드롭 현상을 원천 방지.
  * Uvicorn Keep-Alive 시간을 75초로 증대하고 동시성 제한을 100으로 설정하여 역방향 프록시와 백엔드 간 연결 닫힘 경합 및 502/504 Bad Gateway 완전 해소.
* **초경량 헬스체크 및 하트비트 모니터링**:
  * 무부하 고속 응답(`< 1ms`)의 `GET /api/health`, `GET /healthz` 엔드포인트를 제공하고 25초 주기 브라우저 하트비트를 통해 실시간 연결 상태 점검.
* **지능형 재시도 및 세션 히스토리 자동 복원 (`fetchWithRetry`)**:
  * 일시적 네트워크 순단 시 지수 백오프로 최대 2회 자동 재시도하며, 모바일 화면 꺼짐/백그라운드 복귀(`visibilitychange`, `online`) 시 서버에 이미 저장된 최신 AI 응답을 즉각 동기화하여 메시지 유실 방지.
* **실시간 연결 상태 UI**:
  * 3단계 펄스 인디케이터(`online`, `warning`, `offline`) 및 최상단 연결 상태 배너(`#connection-banner`)와 원클릭 재시도 버튼 제공.

### 3.24. 🎛️ 텔레그램 인터랙티브 인라인 키보드 및 원클릭 태스크 조작 (Interactive Inline Keyboards - ADR-027)
* **정기 브리핑 무타자(Zero-Typing) 인라인 키보드**:
  * 🌅 **아침 브리핑(08:30 KST)**: `[✅ 1순위 태스크 완료]`, `[🔄 GTD 동기화]`, `[📋 전체 할 일 보기]`, `[🚀 원격 푸시]`
  * 🌇 **저녁 일과 회고(20:00 KST)**: `[📝 오늘 일기 작성]`, `[🔄 GTD 동기화]`, `[🚀 오늘 기록 푸시]`, `[📋 내일 할 일 보기]`
* **결정론적 태스크 완료 엔진 (`complete_top_task`)**:
  * Next Actions ➔ 일일 로그 ➔ 수집함(Inbox) 순으로 대기 중인 첫 번째 미완료 항목(`- [ ]`)을 찾아 `- [x]`로 안전하게 전환하고 원자적 Git 커밋/푸시 집행.
  * `/done` 및 `/done [태스크명]` 슬래시 커맨드를 통한 유연한 수동 제어 지원.
* **0.1초 고속 콜백 토스트 및 세션 정합성**:
  * 인라인 버튼 클릭 즉시 `answer_callback_query`로 즉각적인 토스트 피드백을 전달하고, 결과 메시지를 `telegram:{chat_id}` DB 세션에 저장하여 일관된 대화 맥락 보존.

### 3.25 기록 여부 결정론적 검사 및 문두 지시어 라우팅 (ADR-028)
* **기록 여부 질의 결정론적 라우팅 (`log_status_inspect`)**:
  * "오늘 로그 파일에 기록했어?", "기록했어?", "일기 적었어?", "기록 확인" 등 기록 상태 질의를 LLM 대화로 보내지 않고, 실제 디스크 파일 시스템(`logs/daily/YYYY-MM-DD.md`)을 직접 검사하여 사실만을 투명하게 보고.
  * 파일이 있고 일과가 기록된 경우 본문 전문 출력, 파일이 없는 경우 정직하게 미작성 상태를 안내하고 직전 대화 스니펫을 찾아 "응" 한마디로 즉시 기록할 수 있도록 복원 유도.
* **문두(Prefix) 기록 지시어 및 구어체 포괄 (`front_record_pattern`)**:
  * "어제 gtd에 이 내용을 넣어달라구 [본문]", "오늘 일기에 이거 적어줘: [본문]" 등 문장 시작부에 지시어가 오거나 "넣어줘", "업데이트 해줘" 등 자연스러운 구어체 요청 시 완벽히 본문을 추출하여 마크다운 기록 및 Git 커밋 집행.
* **AI 언어모델 시뮬레이션 원천 차단 가드레일**:
  * 백엔드 파일 기록이 실행되지 않은 상태에서 LLM이 가상으로 "정리해 두었습니다/기록했습니다"라고 응답하는 환각을 프롬프트 레벨에서 엄격히 금지.

### 3.26. 📝 2단계 사전 검토 및 원터치 승인 워크플로우 (Two-Phase Draft Review & Confirmation - ADR-029)
* **마크다운 초안 카드 (Draft Preview Card) 제안**:
  * 운동, 아이디어, 업무 성과, 가족/식사/병원 등 삶의 일과를 이야기하면 즉시 마크다운 파일을 수정하지 않고 `log_suggest` 인텐트로 전환하여 타임스탬프(`- [HH:MM]`), 저장될 대상 파일 경로, 카테고리가 정제된 마크다운 초안 카드를 사용자에게 사전 제시.
  * 일상 속 실천 과제(병원 예약, 물품 구입 등) 감지 시 일일 로그 초안과 GTD 인박스 초안(`- [ ]`)을 동시에 미리보기 카드로 구성.
* **텔레그램 & 웹 대시보드 원터치 인라인 액션 버튼**:
  * **텔레그램**: 인라인 키보드 `[✅ 응, 기록해줘]`, `[❌ 아니야]`를 메시지 하단에 동적 부착하여 터치 한 번으로 물리적 디스크 기록 및 원자적 Git 커밋/푸시 집행.
  * **웹 콘솔 (`/watson`)**: 제안 카드 수신 시 퀵 액션 버튼(`[응, 기록해줘]`, `[아니야]`) 동적 렌더링.
* **파워유저 패스트트랙 (`/log`)**:
  * 사전 검토를 생략하고 즉시 기록/커밋을 원하는 경우 `/log [내용]` 커맨드로 0초 만에 직행 가능.
